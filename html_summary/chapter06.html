บทที่ 6: การเรียนรู้ของเครื่อง (Machine Learning: ML)

สรุปหลักการทำงานของ ML, ความแตกต่างจากการเขียนโปรแกรมแบบดั้งเดิม, 3 รูปแบบการเรียนรู้หลัก, วงจร ML Pipeline, การจัดการ Overfitting และการประเมินผลโมเดลด้วยตัวชี้วัดสากล

1. นิยามและแนวคิดพื้นฐาน (Fundamental Paradigm)

Machine Learning (ML): คือการพัฒนาอัลกอริทึมและระบบที่สามารถ "เรียนรู้รูปแบบ (Patterns) จากข้อมูลและยกระดับประสิทธิภาพได้เองจากประสบการณ์" โดยที่มนุษย์ไม่ต้องคอยเขียนโปรแกรมกำหนดเงื่อนไขกฎเกณฑ์ตายตัวทีละข้อ

💡 การเปลี่ยนกระบวนทัศน์ (Paradigm Shift)

Traditional Programming: นำ Data + Rules (มนุษย์คิดกฎ) → Output
Machine Learning: นำ Data + Output (คำตอบตัวอย่าง) → Model / Rules (คอมพิวเตอร์สร้างกฎเอง)

2. องค์ประกอบสำคัญของระบบ ML (Key Components)

📊 1. Data (ข้อมูล)

วัตถุดิบตั้งต้น ประกอบด้วย Features ($X$) และ Labels ($y$)

⚙️ 2. Features (คุณลักษณะ)

ตัวแปรคุณสมบัติที่ใช้เป็น Input นำเข้าสู่โมเดลเพื่อใช้แยกแยะ

📐 3. Model / Algorithm

โครงสร้างคณิตศาสตร์ที่ใช้เรียนรู้ เช่น Decision Tree, Neural Networks

🎯 4. Loss Function

ฟังก์ชันเป้าหมายที่ใช้วัดความคลาดเคลื่อนระหว่างค่าทำนายกับค่าจริง

🔄 5. Training Process

กระบวนการปรับปรุง Parameters/Weights เพื่อให้ค่า Loss ต่ำที่สุด

3. ประเภทของการเรียนรู้ของเครื่อง (Types of ML)

ประเภท ลักษณะข้อมูลนำเข้า เป้าหมายหลัก ตัวอย่างงานสำคัญ
Supervised Learning มีป้ายกำกับเฉลย (Labeled Data) $(X, y)$ สร้างฟังก์ชันทำนาย $y$ จาก $X$ • Classification: จำแนกสแปม, ตรวจจับโรค
• Regression: พยากรณ์ราคาบ้าน, คาดการณ์ยอดขาย
Unsupervised Learning ไม่มีป้ายกำกับ (Unlabeled Data) $(X)$ ค้นหารูปแบบหรือโครงสร้างที่ซ่อนอยู่ • Clustering: แบ่งกลุ่มพฤติกรรมลูกค้า (K-Means)
• Dimensionality Reduction: ลดมิติข้อมูล (PCA)
Reinforcement Learning สภาพแวดล้อมจำลอง (Agent + Environment) สะสมรางวัลสูงสุด (Maximize Cumulative Reward) ผ่านการลองผิดลองถูก AI เล่นเกม (AlphaGo), หุ่นยนต์เดินสองขา, ระบบขับเคลื่อนอัตโนมัติ

4. วงจรการพัฒนา (ML Pipeline) & การแบ่งชุดข้อมูล

Problem Definition → Data Collection → Data Preprocessing & Feature Engineering → Model Training → Model Evaluation → Deployment

การแบ่งชุดข้อมูล (Data Splitting Strategy)

Training Set (~70%)

ใช้สำหรับสอนโมเดล ให้โมเดลปรับจูนพารามิเตอร์ภายใน (Weights/Biases)

Validation Set (~15%)

ใช้สำหรับคัดเลือกสถาปัตยกรรมโมเดลและปรับจูน Hyperparameters

Testing Set (~15%)

ข้อสอบชุดสุดท้ายที่ใช้ประเมินประสิทธิภาพ (ห้ามใช้เทรนเด็ดขาด เพื่อป้องกัน Data Leakage)

5. การสรุปผลทั่วไป, Underfitting และ Overfitting

สภาวะ พฤติกรรมบนชุดข้อมูล สาเหตุหลัก แนวทางแก้ไข
Underfitting
(High Bias)		 แม่นยำต่ำทั้งบน Training Set และ Testing Set โมเดลเรียบง่ายเกินไป ไม่สามารถจับรูปแบบความสัมพันธ์ของข้อมูลได้ เพิ่มความซับซ้อนของโมเดล, เพิ่มจำนวนฟีเจอร์, ลด Regularization
Overfitting
(High Variance)		 แม่นยำสูงมากบน Training Set (ใกล้ 100%) แต่แม่นยำต่ำมากบน Testing Set โมเดลซับซ้อนเกินไป จนจดจำสัญญาณรบกวน (Noise) ในชุดฝึกสอน ลดความซับซ้อนของโมเดล, เพิ่มข้อมูลฝึก, ทำ Regularization (L1/L2), ทำ Pruning

6. ตัวชี้วัดประสิทธิภาพ (Evaluation Metrics)

6.1 งาน Classification (Confusion Matrix)

Predicted Positive (ทายว่าเป็น) Predicted Negative (ทายว่าไม่เป็น)
Actual Positive (ของจริงเป็น) True Positive (TP) False Negative (FN) (หลุดตรวจไม่พบ)
Actual Negative (ของจริงไม่เป็น) False Positive (FP) (ทายเกิน/แจ้งเตือนผิด) True Negative (TN)
Accuracy

(TP + TN) / (TP + TN + FP + FN) วัดความถูกต้องภาพรวม เหมาะกับข้อมูลที่สมดุล (Balanced Data)

Precision

TP / (TP + FP) ความถูกต้องเมื่อทายว่าเป็นบวก เน้นลด FP (เช่น ระบบกรองสแปม ไม่ให้เมลสำคัญตกถังขยะ)

Recall (Sensitivity)

TP / (TP + FN) ความครอบคลุมในการตรวจจับ เน้นลด FN (เช่น การตรวจคัดกรองโรคมะเร็ง ห้ามหลุดตรวจไม่พบ)

F1-Score

2 * (Precision * Recall) / (Precision + Recall) ค่าเฉลี่ยฮาร์มอนิก เหมาะสำหรับข้อมูลไม่สมดุล (Imbalanced Data)

6.2 งาน Regression & Clustering

• MAE: ค่าเฉลี่ยผลต่างสัมบูรณ์ ตีความง่ายตรงไปตรงมา
• MSE: ยกกำลังสองของผลต่าง ลงโทษข้อผิดพลาดขนาดใหญ่
• RMSE: ถอดรากของ MSE ได้หน่วยเดียวกับตัวแปรจริง
• R²: สัดส่วนความแปรปรวนที่โมเดลอธิบายได้ (ใกล้ 1 คือดีเยี่ยม)
• Silhouette Score: วัดประสิทธิภาพการจัดกลุ่ม (Clustering) ช่วงค่า [-1, 1] (ยิ่งใกล้ +1 ยิ่งเกาะกลุ่มแน่นและแยกขาดจากกลุ่มอื่น)
