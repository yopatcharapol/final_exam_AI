บทที่ 8: โครงข่ายประสาทเทียม (Artificial Neural Network: ANN)

1. แนวคิดและโครงสร้างของนิวรอนเทียม (Artificial Neuron)

จำลองการทำงานจากเซลล์ประสาทชีวภาพ (Biological Neuron) โดยแปลงสัญญาณเคมีไฟฟ้าเป็นแบบจำลองทางคณิตศาสตร์:

Net Input (z) = ∑ (w_i × x_i) + b   |   Output (y) = f(z)
📥 Input (x_i)

สัญญาณหรือคุณลักษณะที่ส่งเข้ามาสู่นิวรอน (เปรียบเสมือน Dendrite)

⚖️ Weight (w_i)

ค่าน้ำหนักถ่วง กำหนดความสำคัญและอิทธิพลของแต่ละตัวแปร (เปรียบเสมือน Synaptic Strength)

🎚️ Bias (b)

ค่าไบแอส เลื่อนระดับการกระตุ้น (Shift threshold) ช่วยให้โมเดลไม่ถูกจำกัดให้เส้นต้องตัดจุดกำเนิด (0,0)

⚡ Activation Function f(z)

ฟังก์ชันกระตุ้น กำหนดว่านิวรอนจะยิงสัญญาณ (Fire) ออกไปในระดับความแรงเท่าใด

2. ฟังก์ชันกระตุ้นที่สำคัญ (Activation Functions)

ฟังก์ชัน สูตรคณิตศาสตร์ ช่วงค่าผลลัพธ์ การนำไปใช้งาน & จุดเด่น
Step Function f(z) = 1 if z ≥ 0 else 0 {0, 1} ใช้ใน Perceptron ยุคแรก (Binary threshold) หาอนุพันธ์ไม่ได้
Sigmoid σ(z) = 1 / (1 + e^(-z)) (0, 1) นิยมใช้ที่ Output Layer สำหรับ Binary Classification (ตีความเป็นความน่าจะเป็น)
Tanh tanh(z) = (e^z - e^(-z)) / (e^z + e^(-z)) (-1, 1) Zero-centered (กึ่งกลางอยู่ที่ 0) ช่วยให้การลู่เข้าของ Gradient เสถียรกว่า Sigmoid
ReLU f(z) = max(0, z) [0, ∞) มาตรฐานสูงสุดใน Hidden Layer คำนวณเร็วมาก และไม่เกิด Vanishing Gradient ในโซนบวก
Softmax Softmax(z_i) = e^(z_i) / ∑ e^(z_j) (0, 1), ∑ = 1 Output Layer สำหรับ Multiclass Classification แปลงคะแนนเป็นความน่าจะเป็นที่รวมกันได้ 1 พอดี

3. เพอร์เซปตรอนและโครงข่ายหลายชั้น (Perceptron vs MLP)

⚠️ วิกฤตปัญหา XOR ของ Single Layer Perceptron (1969)

Single Layer Perceptron มีเพียงเส้นแบ่งตรง (Hyperplane) เส้นเดียว สามารถแก้ปัญหาที่ แยกขาดด้วยเส้นตรง (Linearly Separable) ได้ เช่น AND, OR แต่ ไม่สามารถแก้ปัญหาฟังก์ชันตรรกะ XOR ได้ ซึ่งทำให้เกิดยุคตกต่ำของ AI (AI Winter)

💡 การก้าวข้ามด้วย Multi-Layer Perceptron (MLP)

เมื่อเพิ่ม Hidden Layer (ชั้นซ่อน) และใช้ Non-linear Activation Functions โครงข่ายจะสามารถบิดงอและรวมเส้นแบ่งตรงหลายเส้นเข้าด้วยกัน จนสามารถจำลองพื้นที่การตัดสินใจที่โค้งงอซับซ้อน และแก้ปัญหา XOR รวมถึงปัญหาในโลกจริงได้อย่างสมบูรณ์แบบ

4. วงจรการฝึกสอนโครงข่าย (Training Pipeline)

ขั้นตอน ชื่อกระบวนการ รายละเอียดการทำงาน
1 Forward Propagation ส่งสัญญาณอินพุตผ่านค่าน้ำหนัก ไบแอส และฟังก์ชันกระตุ้น จากเลเยอร์แรกไปจนถึงเลเยอร์สุดท้ายเพื่อหาผลทำนาย (ŷ)
2 Loss Computation คำนวณหาค่าความคลาดเคลื่อนเทียบกับเฉลยจริง เช่น MSE (Mean Squared Error) หรือ Cross-Entropy Loss
3 Backpropagation คำนวณหาความชัน (Gradients: ∂Loss / ∂W) ย้อนกลับจากท้ายมาหน้า โดยอาศัย กฎลูกโซ่ของแคลคูลัส (Chain Rule)
4 Gradient Descent ปรับปรุงค่าน้ำหนักตามสมการ: W ← W - η × (∂Loss / ∂W)
*(โดย η คือ Learning Rate ซึ่งคุมขนาดก้าว หากสูงไปจะแกว่งหลุดต่ำสุด หากต่ำไปจะเรียนรู้ช้ามาก)*

5. ประเภทหลักของโครงข่ายประสาทเทียม

FNN (Feedforward)

สัญญาณเดินทางทิศทางเดียวจากหน้าไปหลัง ไม่มีลูปย้อนกลับ เหมาะกับข้อมูลตารางและตัวเลขทั่วไป

CNN (Convolutional)

ออกแบบมาเพื่อสกัดคุณลักษณะเชิงพื้นที่ (Spatial) เหมาะกับข้อมูลภาพดิจิทัลและวิดีโอ

RNN (Recurrent)

มีวงจรป้อนกลับ (Feedback Loop) จำบริบทในอดีตได้ เหมาะกับข้อมูลลำดับเวลา (Time-series) และภาษา (NLP)
