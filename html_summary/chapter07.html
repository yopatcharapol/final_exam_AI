Decision Trees

บทที่ 7: ต้นไม้ตัดสินใจ (Decision Tree)

เจาะลึกโครงสร้างต้นไม้กลับหัว, สูตรคณิตศาสตร์ Gini Impurity & Entropy, การแตกกิ่งในงาน Classification และ Regression, เทคนิคการตัดแต่งกิ่ง (Pruning) และจุดเด่น White-box

📑 หัวข้อในบทนี้

1. นิยามและโครงสร้างของต้นไม้ตัดสินใจ (Tree Anatomy)

Decision Tree: เป็นโมเดลประเภท Supervised Learning ที่จำแนกข้อมูลหรือทำนายผลลัพธ์ผ่านลำดับกฎเกณฑ์เงื่อนไข (If-Else Rules) มีโครงสร้างเป็นลำดับชั้นคล้ายต้นไม้กลับหัว:

🌱 Root Node (โหนดราก)

โหนดแรกสุดด้านบนสุดของต้นไม้ ทำหน้าที่ทดสอบฟีเจอร์ที่แยกข้อมูลได้ทรงพลังที่สุด

🌿 Internal Node (โหนดภายใน)

โหนดทดสอบเงื่อนไขย่อย (Decision Node) ซึ่งจะแตกกิ่งออกตามค่าของเงื่อนไข

🪵 Branch (กิ่ง)

เส้นทางเชื่อมโยงผลลัพธ์ของเงื่อนไข (เช่น จริง/เท็จ หรือ ≥ ค่า Threshold)

🍃 Leaf Node (โหนดใบ)

โหนดปลายสุด (Terminal Node) บรรจุผลลัพธ์คำทำนายสุดท้าย โดยไม่มีกิ่งก้านแตกออกไปอีก

2. ฟังก์ชันเกณฑ์วัดความไม่บริสุทธิ์ (Impurity Criteria)

ในการแตกกิ่ง อัลกอริทึมจะเลือกฟีเจอร์และจุดตัด (Threshold) ที่ทำให้โหนดลูกมี ความบริสุทธิ์สูงสุด (Maximum Purity) หรือลด ความไม่บริสุทธิ์ (Impurity) ลงได้มากที่สุด

1) Gini Impurity (ดัชนีจินี - นิยมใน CART)
Gini(D) = 1 - ∑ (p_i)²

• ช่วงค่า: 0 ถึง 0.5 สำหรับปัญหา 2 คลาส
• ค่า 0: หมายถึงโหนดมีความบริสุทธิ์ 100% (ข้อมูลเป็นคลาสเดียวกันทั้งหมด)
• ค่า 0.5: หมายถึงความไม่บริสุทธิ์สูงสุด (ข้อมูลแบ่งครึ่ง 50/50)

2) Entropy & Information Gain (นิยมใน ID3, C4.5)
Entropy(D) = - ∑ p_i × log&sub2;(p_i)
Gain(D, A) = Entropy(D) - ∑ (|D_v| / |D|) × Entropy(D_v)

• Entropy: วัดระดับความไม่เป็นระเบียบหรือความสุ่มของข้อมูล (ช่วงค่า 0 ถึง 1 สำหรับ 2 คลาส)
• Information Gain: ปริมาณความไม่เป็นระเบียบที่ลดลงหลังจากการแบ่งโหนด อัลกอริทึมจะเลือกฟีเจอร์ที่ให้ Information Gain สูงสุด

3. ต้นไม้ตัดสินใจสำหรับงานถดถอย (Decision Tree Regression)

เมื่อนำ Decision Tree ไปใช้พยากรณ์ตัวเลขต่อเนื่อง (เช่น พยากรณ์ราคา หรืออุณหภูมิ):

เกณฑ์การแตกกิ่ง (Splitting Criterion)

ใช้การลดค่าความคลาดเคลื่อน MSE (Mean Squared Error) หรือ MAE (Mean Absolute Error) ของกลุ่มตัวอย่างในโหนด

ค่าทำนายในโหนดใบ (Leaf Prediction)

ผลลัพธ์ใน Leaf Node จะคำนวณจาก ค่าเฉลี่ย (Mean) ของค่าเป้าหมายทั้งหมดที่ตกลงมาในโหนดนั้น

4. ปัญหา Overfitting และการตัดแต่งกิ่ง (Pruning)

หากปล่อยให้ต้นไม้แตกกิ่งอย่างอิสระโดยไม่ควบคุม ต้นไม้จะลึกมากจนจดจำข้อมูลทุกแถว ส่งผลให้เกิด Overfitting อย่างรุนแรง จึงต้องควบคุมความซับซ้อนด้วยเทคนิค Pruning 2 รูปแบบ:

ประเภทการตัดแต่งกิ่ง วิธีการและจังหวะการทำงาน Hyperparameters ที่สำคัญ
Pre-pruning
(Early Stopping)		 ตั้งกฎเกณฑ์หยุดการแตกกิ่งล่วงหน้าระหว่างที่กำลังฝึกสอนโมเดล • max_depth: กำหนดความลึกสูงสุดของต้นไม้
• min_samples_split: จำนวนตัวอย่างขั้นต่ำที่ยอมให้แบ่งโหนดต่อ
• min_samples_leaf: จำนวนตัวอย่างขั้นต่ำที่ต้องคงอยู่ในโหนดใบ
• max_leaf_nodes: จำนวนโหนดใบสูงสุด
Post-pruning
(Cost Complexity)		 ปล่อยให้ต้นไม้เติบโตจนสุดเต็มที่ก่อน แล้วค่อยวิเคราะห์ย้อนหลังเพื่อตัดกิ่งก้านที่ไม่ส่งผลดีต่อประสิทธิภาพทิ้ง • ccp_alpha: ค่าพารามิเตอร์ควบคุมโทษความซับซ้อน (Cost-Complexity Parameter)

5. ข้อดีและข้อจำกัดของ Decision Tree

✅ ข้อดีที่โดดเด่น

1. Explainable (White-box): อธิบายเหตุผลได้ง่าย แสดงเป็นแผนภาพกฎ If-Else ให้ผู้บริหารหรือแพทย์เข้าใจได้ชัดเจน
2. รองรับข้อมูลหลากหลาย: ใช้ได้ทั้งข้อมูลตัวเลข (Numerical) และข้อมูลหมวดหมู่ (Categorical)
3. ไม่ต้องทำ Feature Scaling: ไม่จำเป็นต้อง Normalized/Standardized ข้อมูล เพราะต้นไม้พิจารณา Threshold ทีละฟีเจอร์แยกกัน

⚠️ ข้อจำกัดสำคัญ

1. เสี่ยง Overfitting: หากต้นไม้ลึกเกินไปจะเกิด Variance สูงมาก
2. Instability (ขาดความเสถียร): ข้อมูลเปลี่ยนแปลงเพียงเล็กน้อย อาจทำให้รูปทรงของต้นไม้เปลี่ยนไปอย่างสิ้นเชิง
3. Greedy Search: เลือกจุดแบ่งที่ดีที่สุดในจุดนั้นๆ (Local Optimum) ซึ่งอาจไม่ใช่โครงสร้างที่ดีที่สุดในภาพรวม (Global Optimum)
