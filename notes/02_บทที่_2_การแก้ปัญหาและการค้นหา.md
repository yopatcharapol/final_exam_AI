---

## 1. การกำหนดปัญหา (Problem Formulation)
การแก้ปัญหาใน AI ประกอบด้วย 5 องค์ประกอบพื้นฐาน:
1. **Initial State ($):** สถานะเริ่มต้นของปัญหา
2. **Actions ((s)$):** เซตของการกระทำที่เป็นไปได้ในสถานะ $
3. **Transition Model ((s, a)$):** สถานะผลลัพธ์ที่เกิดขึ้นเมื่อทำ Action $ ในสถานะ $
4. **Goal Test:** ฟังก์ชันตรวจสอบว่าสถานะปัจจุบันคือสถานะเป้าหมายหรือไม่
5. **Path Cost ((s, a, s')$):** ค่าใช้จ่ายหรือต้นทุนในการเดินทางจากสถานะหนึ่งไปยังอีกสถานะหนึ่ง

---

## 2. ปริภูมิสถานะ (State Space) และกราฟการค้นหา (Search Tree/Graph)
* **State Space:** เซตของสถานะทั้งหมดที่สามารถเข้าถึงได้จากการกระทำต่าง ๆ
* **Node ใน Search Tree:** ประกอบด้วย State, Parent Node, Action, Path-Cost (g(n)), Depth
* **Frontier (Open List):** โครงสร้างข้อมูลที่เก็บโหนดที่ค้นพบแล้วแต่ยังไม่ได้ถูกขยาย (Expand)
* **Explored Set (Closed List):** เซตที่เก็บโหนดที่ผ่านการขยายแล้วเพื่อป้องกันการวนลูป (Loop/Cycle)

---

## 3. การประเมินประสิทธิภาพของอัลกอริทึมการค้นหา
1. **Completeness (ความสมบูรณ์):** รับประกันว่าจะพบคำตอบเสมอหรือไม่หากมีคำตอบอยู่จริง
2. **Time Complexity (ความซับซ้อนด้านเวลา):** จำนวนโหนดที่ต้องสร้างหรือขยาย
3. **Space Complexity (ความซับซ้อนด้านหน่วยความจำ):** จำนวนโหนดสูงสุดที่ต้องเก็บไว้ในหน่วยความจำ
4. **Optimality (ความเหมาะสมที่สุด):** รับประกันว่าจะพบคำตอบที่มี Path Cost ต่ำที่สุดหรือไม่
*(ตัวแปร: $ = Branching Factor, $ = Depth ของตื้นสุดที่เป็นเป้าหมาย, $ = Maximum Depth ของต้นไม้)*

## 5. การค้นหาแบบมีสารสนเทศ (Informed / Heuristic Search)
ใช้ฟังก์ชันฮิวริสติก (n)$ ซึ่งเป็นการประมาณค่าต้นทุนจากโหนด $ ไปยังเป้าหมาย

### 5.1 Greedy Best-First Search
* ขยายโหนดที่มีค่า (n) = h(n)$ น้อยที่สุด
* **ข้อดี:** วิ่งเข้าหาเป้าหมายได้เร็ว
* **ข้อเสีย:** ไม่สมบูรณ์ (Incomplete) และไม่ได้คำตอบที่เหมาะสมที่สุด (Non-optimal) อาจติดหล่มได้

### 5.2 A* Search (A-Star Search)
* ฟังก์ชันประเมิน: **(n) = g(n) + h(n)$**
  * (n)$ = ต้นทุนจริงจากจุดเริ่มต้นถึงโหนด $
  * (n)$ = ต้นทุนประมาณการจากโหนด $ ถึงเป้าหมาย
* **คุณสมบัติเพื่อรับประกัน Optimality ของ A*:**
  1. **Admissible Heuristic (สำหรับ Tree Search):**  \le h(n) \le h^*(n)$ (ห้ามประเมินต้นทุนสูงเกินจริง / Never overestimates)
  2. **Consistent / Monotonic Heuristic (สำหรับ Graph Search):** (n) \le c(n, a, n') + h(n')$ (สอดคล้องกับอสมการสามเหลี่ยม)

## 6. ข้อสรุปสำคัญสำหรับสอบ
* **IDDFS:** รวมข้อดีของ BFS (Complete + Optimal) และ DFS (ประหยัดหน่วยความจำ (bd)$)
* **A* Search:** เป็นอัลกอริทึมการค้นหาที่มีประสิทธิภาพสูงสุดหากฮิวริสติกเป็น Admissible และ Consistent
