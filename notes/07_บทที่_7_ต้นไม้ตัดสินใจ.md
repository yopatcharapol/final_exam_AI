# สรุปบทที่ 7: ต้นไม้ตัดสินใจ (Decision Tree)

---

## 1. นิยามและโครงสร้างของต้นไม้ตัดสินใจ
ต้นไม้ตัดสินใจเป็นโมเดลแบบ Supervised Learning ที่จำแนกข้อมูลหรือทำนายผลลัพธ์ผ่านลำดับของกฎเงื่อนไข (If-Else) มีโครงสร้างคล้ายต้นไม้กลับหัว:
* **Root Node (โหนดราก):** โหนดแรกสุดด้านบนสุด ทำหน้าที่ทดสอบฟีเจอร์ที่สำคัญที่สุด
* **Internal Node (โหนดภายใน / Decision Node):** โหนดที่ทดสอบเงื่อนไขของคุณลักษณะย่อย
* **Branch (กิ่ง):** เส้นทางเชื่อมต่อผลลัพธ์ของเงื่อนไข
* **Leaf Node (โหนดใบ / Terminal Node):** โหนดปลายสุด บรรจุผลการทำนาย (ไม่มีกิ่งออก)

---

## 2. ฟังก์ชันเกณฑ์ (Criterion Function) สำหรับเลือกจุดแบ่งข้อมูล
อัลกอริทึมต้นไม้ตัดสินใจจะเลือกฟีเจอร์และจุดตัด (Threshold) ที่ทำให้กลุ่มย่อยมี **ความบริสุทธิ์สูงสุด (Maximum Purity)** หรือลด **ความไม่บริสุทธิ์ (Impurity)** ลงมากที่สุด

### 2.1 สำหรับงาน Classification
1. **Gini Impurity (ดัชนีจินี - นิยมในอัลกอริทึม CART):**
   $$\text{Gini}(D) = 1 - \sum_{i=1}^{k} p_i^2$$
   *(ช่วงค่า $0$ ถึง $0.5$ สำหรับ 2 คลาส โดย $0$ หมายถึงบริสุทธิ์ 100%)*
2. **Entropy (เอนโทรปี - นิยมในอัลกอริทึม ID3, C4.5):**
   $$\text{Entropy}(D) = -\sum_{i=1}^{k} p_i \log_2 p_i$$
   *(ช่วงค่า $0$ ถึง $1$ สำหรับ 2 คลาส)*
3. **Information Gain (เกนสารสนเทศ):**
   $$\text{Gain}(D, A) = \text{Entropy}(D) - \sum_{v \in \text{Values}(A)} \frac{|D_v|}{|D|} \text{Entropy}(D_v)$$

### 2.2 สำหรับงาน Regression (Decision Tree Regression)
* ใช้ **MSE (Mean Squared Error)** หรือ **MAE (Mean Absolute Error)** ในการประเมิน
* ผลลัพธ์ใน Leaf Node จะเป็น **ค่าเฉลี่ย (Mean)** ของกลุ่มข้อมูลในโหนดนั้น

## 3. การเกิด Overfitting และการตัดแต่งกิ่ง (Pruning)
ต้นไม้ตัดสินใจที่ลึกมากเกินไปจะเกิด Overfitting ได้ง่าย จึงต้องควบคุมความซับซ้อน:
1. **Pre-pruning (Early Stopping):** หยุดการแตกกิ่งระหว่างฝึกสอนผ่าน Hyperparameters:
   * `max_depth`: ความลึกสูงสุดของต้นไม้
   * `min_samples_split`: จำนวนข้อมูลขั้นต่ำที่ยอมให้แบ่งโหนดต่อ
   * `min_samples_leaf`: จำนวนข้อมูลขั้นต่ำที่ต้องมีอยู่ในโหนดใบ
   * `max_leaf_nodes`: จำนวนโหนดใบสูงสุด
2. **Post-pruning (Cost Complexity Pruning):** สร้างต้นไม้ให้โตเต็มที่ก่อน แล้วตัดกิ่งที่ให้ผลตอบแทนต่ำออกภายหลัง

---

## 4. ข้อดีและข้อจำกัดของ Decision Tree
* **ข้อดี:**
  1. อธิบายเหตุผลได้ง่าย (Explainable / White-box Model) แสดงภาพได้ชัดเจน
  2. รองรับทั้งข้อมูลตัวเลข (Numerical) และข้อมูลเชิงกลุ่ม (Categorical)
  3. ไม่จำเป็นต้องแปลงสเกลข้อมูล (No feature scaling required)
* **ข้อจำกัด:**
  1. ไวต่อการเกิด Overfitting
  2. ขาดความเสถียร (Instability) ข้อมูลเปลี่ยนเล็กน้อยอาจได้ต้นไม้คนละทรง
  3. ใช้การค้นหาแบบ Greedy Search อาจติด Local Optimum
