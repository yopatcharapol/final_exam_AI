# สรุปบทที่ 6: การเรียนรู้ของเครื่อง (Machine Learning: ML)

---

## 1. นิยามและแนวคิดพื้นฐาน
* **Machine Learning:** การสร้างระบบที่สามารถเรียนรู้รูปแบบ (Patterns) จากข้อมูลและพัฒนาประสิทธิภาพได้เองจากประสบการณ์ โดยไม่ต้องเขียนโปรแกรมกำหนดกฎตายตัว
* **Traditional Programming vs. Machine Learning:**
  * **Traditional:** Data + Rules $\rightarrow$ Output
  * **Machine Learning:** Data + Output $\rightarrow$ Model / Rules

---

## 2. องค์ประกอบสำคัญของระบบ ML
1. **Data (ข้อมูล):** วัตถุดิบหลัก ประกอบด้วย Features และ Labels
2. **Features (คุณลักษณะ):** ตัวแปรคุณสมบัติที่ใช้เป็น Input ($X$)
3. **Model / Algorithm (แบบจำลอง/อัลกอริทึม):** โครงสร้างคณิตศาสตร์ที่ใช้เรียนรู้ (เช่น Decision Tree, Neural Network)
4. **Loss / Objective Function (ฟังก์ชันเป้าหมาย):** ใช้วัดความคลาดเคลื่อนของการทำนาย
5. **Training Process (กระบวนการฝึกสอน):** การปรับปรุงค่าน้ำหนักหรือพารามิเตอร์เพื่อให้ Loss ต่ำที่สุด

---

## 3. ประเภทของการเรียนรู้ของเครื่อง (Types of Machine Learning)

| ประเภท | ลักษณะข้อมูล | เป้าหมายหลัก | ตัวอย่างงาน |
| :--- | :--- | :--- | :--- |
| **Supervised Learning** | มีป้ายกำกับ (Labeled Data) $(X, y)$ | ทำนาย $y$ จาก $X$ | **Classification** (สแปม/ไม่สแปม)<br>**Regression** (พยากรณ์ราคาบ้าน) |
| **Unsupervised Learning** | ไม่มีป้ายกำกับ (Unlabeled Data) $(X)$ | ค้นหารูปแบบ/โครงสร้างที่ซ่อนอยู่ | **Clustering** (แบ่งกลุ่มลูกค้า)<br>**Dimensionality Reduction** (PCA) |
| **Reinforcement Learning** | สภาพแวดล้อมจำลอง (Agent + Environment) | สะสมรางวัลสูงสุด (Maximize Cumulative Reward) | AI เล่นเกม (AlphaGo), หุ่นยนต์เดิน, รถไร้คนขับ |

---

## 4. กระบวนการพัฒนาโมเดล (ML Pipeline)
$$\text{Problem Definition} \rightarrow \text{Data Collection} \rightarrow \text{Data Preprocessing & Feature Engineering} \rightarrow \text{Model Training} \rightarrow \text{Model Evaluation & Tuning} \rightarrow \text{Deployment}$$

### การแบ่งชุดข้อมูล (Data Splitting):
* **Training Set (~70%):** ใช้สอนและปรับแต่งพารามิเตอร์ของโมเดล
* **Validation Set (~15%):** ใช้เลือกโมเดลและปรับจูน Hyperparameters
* **Testing Set (~15%):** ใช้ประเมินประสิทธิภาพขั้นสุดท้าย (ห้ามใช้เทรนเด็ดขาด เพื่อป้องกัน Data Leakage)

---

## 5. การสรุปผลทั่วไป, Underfitting และ Overfitting
* **Generalization:** ความสามารถในการทำนายข้อมูลใหม่ที่ไม่เคยเห็นมาก่อนได้อย่างแม่นยำ
* **Underfitting (High Bias):** โมเดลง่ายเกินไป เรียนรู้รูปแบบไม่ได้ แม่นยำต่ำทั้งบน Train และ Test $\rightarrow$ *วิธีแก้: เพิ่มความซับซ้อนของโมเดล, เพิ่มฟีเจอร์*
* **Overfitting (High Variance):** โมเดลซับซ้อนเกินไป จำ Noise ใน Train Data ได้ 100% แต่ Test แม่นยำต่ำมาก $\rightarrow$ *วิธีแก้: ลดความซับซ้อน, เพิ่มข้อมูล, ทำ Regularization, ทำ Pruning*

---

## 6. ตัวชี้วัดประสิทธิภาพ (Evaluation Metrics)

### 6.1 งาน Classification (Confusion Matrix)
| | Predicted Positive | Predicted Negative |
| :---: | :---: | :---: |
| **Actual Positive** | **True Positive (TP)** | **False Negative (FN)** |
| **Actual Negative** | **False Positive (FP)** | **True Negative (TN)** |

* **Accuracy:** $\frac{TP + TN}{TP + TN + FP + FN}$ (วัดภาพรวม เหมาะกับ Balanced Data)
* **Precision:** $\frac{TP}{TP + FP}$ (ความถูกต้องเมื่อทายว่าเป็นบวก เน้นลด FP เช่น ระบบสแปม)
* **Recall (Sensitivity):** $\frac{TP}{TP + FN}$ (ความครอบคลุมในการตรวจจับ เน้นลด FN เช่น ตรวจมะเร็ง)
* **F1-Score:** $2 \times \frac{\text{Precision} \times \text{Recall}}{\text{Precision} + \text{Recall}}$ (ค่าเฉลี่ยฮาร์มอนิก เหมาะกับ Imbalanced Data)
* **ROC-AUC:** พื้นที่ใต้กราฟ ROC ยิ่งใกล้ 1 ยิ่งแยกแยะคลาสได้ดีเยี่ยม

### 6.2 งาน Regression
* **MAE (Mean Absolute Error):** $\frac{1}{n}\sum |y - \hat{y}|$
* **MSE (Mean Squared Error):** $\frac{1}{n}\sum (y - \hat{y})^2$ (ลงโทษความผิดพลาดขนาดใหญ่)
* **RMSE (Root Mean Squared Error):** $\sqrt{\text{MSE}}$ (หน่วยเดียวกับตัวแปรจริง)
* **$R^2$ (Coefficient of Determination):** สัดส่วนความแปรปรวนที่โมเดลอธิบายได้ (ค่าเข้าใกล้ 1 คือดี)

### 6.3 งาน Clustering (Unsupervised)
* **Silhouette Score:** ช่วงค่า $[-1, 1]$ ยิ่งใกล้ $+1$ ยิ่งจัดกลุ่มได้ดี
* **Davies-Bouldin Index:** ค่ายิ่งน้อยยิ่งดี
* **Calinski-Harabasz Index:** ค่ายิ่งมากยิ่งดี
