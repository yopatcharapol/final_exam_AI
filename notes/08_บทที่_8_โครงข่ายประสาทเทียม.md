# สรุปบทที่ 8: โครงข่ายประสาทเทียม (Artificial Neural Network: ANN)

---

## 1. แนวคิดและโครงสร้างของนิวรอนเทียม (Artificial Neuron)
จำลองการทำงานจากเซลล์ประสาทชีวภาพ (Biological Neuron):
* **Input ($x_i$):** สัญญาณนำเข้า
* **Weight ($w_i$):** ค่าน้ำหนักถ่วง กำหนดความสำคัญของแต่ละ Input
* **Transfer Function (Net Input):** ผลรวมเชิงเส้นถ่วงน้ำหนัก:
  $$z = \sum_{i=1}^{n} w_i x_i + b$$
* **Bias ($b$ หรือ $\beta$):** ค่าไบแอส ชดเชยและเลื่อนระดับการกระตุ้น (ค่า Error ที่ยอมรับได้)
* **Activation Function ($f(z)$):** ฟังก์ชันกระตุ้น ตัดสินใจว่า Output จะถูกยิงออกไปอย่างไร:
  $$y = f(z)$$

---

## 2. ฟังก์ชันกระตุ้นที่สำคัญ (Activation Functions)
| ฟังก์ชัน | สูตรทางคณิตศาสตร์ | ช่วงค่า (Range) | การนำไปใช้งาน |
| :--- | :--- | :---: | :--- |
| **Step Function** | $f(z) = 1 \text{ if } z \ge 0 \text{ else } 0$ | $\{0, 1\}$ | Perceptron ดั้งเดิม (Binary threshold) |
| **Sigmoid** | $\sigma(z) = \frac{1}{1 + e^{-z}}$ | $(0, 1)$ | Output Layer สำหรับ Binary Classification |
| **Tanh** | $\tanh(z) = \frac{e^z - e^{-z}}{e^z + e^{-z}}$ | $(-1, 1)$ | Zero-centered เรียนรู้ได้เสถียรกว่า Sigmoid |
| **ReLU** | $f(z) = \max(0, z)$ | $[0, \infty)$ | มาตรฐานใน Hidden Layers คำนวณเร็ว ลด Vanishing Gradient |
| **Softmax** | $\text{Softmax}(z_i) = \frac{e^{z_i}}{\sum e^{z_j}}$ | $(0, 1), \sum = 1$ | Output Layer สำหรับ Multiclass Classification |

---

## 3. เพอร์เซปตรอนและโครงข่ายหลายชั้น (Perceptron & MLP)
* **Single Layer Perceptron:**
  * มีเพียง Input และ Output
  * แก้ปัญหาได้เฉพาะ **Linearly Separable Problems** (เช่น AND, OR) **ไม่สามารถแก้ XOR ได้**
* **Multi-Layer Perceptron (MLP):**
  * ประกอบด้วย **Input Layer $\rightarrow$ Hidden Layer(s) $\rightarrow$ Output Layer**
  * เมื่อใช้ Non-linear Activation Functions จะสามารถแก้ปัญหาที่ไม่เป็นเส้นตรงและซับซ้อนสูง (เช่น XOR) ได้สมบูรณ์

---

## 4. กระบวนการฝึกสอนโครงข่าย (Training Process)
1. **Forward Propagation:** ส่งข้อมูลผ่าน Weights, Bias และ Activation Functions จนได้ Output ทำนาย ($\hat{y}$)
2. **Loss Function:** คำนวณความคลาดเคลื่อน เช่น Mean Squared Error (MSE) หรือ Cross-Entropy Loss
3. **Backpropagation:** คำนวณความชัน (Gradients: $\frac{\partial L}{\partial W}, \frac{\partial L}{\partial b}$) ย้อนกลับจากชั้นหลังมาหน้าโดยใช้กฎลูกโซ่ (Chain Rule)
4. **Gradient Descent:** ปรับปรุงค่าน้ำหนักและไบแอส:
   $$W \leftarrow W - \eta \frac{\partial L}{\partial W}$$
   *(โดย $\eta$ คือ Learning Rate)*

---

## 5. ประเภทหลักของ Neural Networks
* **FNN (Feedforward Neural Networks):** สัญญาณเดินทางทิศทางเดียว เหมาะกับข้อมูลตารางทั่วไป
* **CNN (Convolutional Neural Networks):** เด่นเรื่องมิติเชิงพื้นที่ เหมาะกับงานภาพ (Image Processing)
* **RNN (Recurrent Neural Networks):** มี Feedback Loop จำบริบทในอดีตได้ เหมาะกับข้อมูลลำดับเวลาและข้อความ (Sequential/NLP)
