โครงข่ายประสาทเทียม 
 
โครงข่ายประสาทเทียม หรือ  Artificial Neural Network (ANN) เป็นหนึ่งใน แบบจำลองสำคัญของ
การเรียนรู้ของเครื่องที่ใช้สำหรับเรียนรู้ความสัมพันธ์และรูปแบบจากข้อมูล แตกต่างจากระบบปัญญาประดิษฐ์
ที่อาศัยการกำหนดกฎหรือเงื่อนไขโดยตรง โครงข่ายประสาทเทียมสามารถปรับค่าพารามิเตอร์ภายใน
แบบจำลองจากข้อมูลตัวอย่าง เพื่อให้สามารถสร้างผลลัพธ์ที่เหมาะสมกับปัญหาได้ 
เนื้อหาในบทที่ผ่านมาได้แสดงให้เห็นว่า ปัญญาประดิษฐ์สามารถแก้ปัญหาได้ด้วยหลายแนวทาง เช่น 
การค้นหา การแทนความรู้และการให้เหตุผล รวมถึงการเรียนรู้ของเครื่อง ในบทที่ 6 และบทที่ 7 ได้ศึกษาการ
สร้างแบบจำลองที่เรียนรู้จากข้อมูล โดยเฉพาะต้นไม้ตัดสินใจ ซึ่งสร้างกระบวนการตัดสินใจจากการแบ่งข้อมูล
ตามคุณลักษณะต่าง ๆ โครงข่ายประสาทเทียมเป็นอีกแนวทางหนึ่งของการเรียนรู้ของเครื่องที่เหมาะสำหรับ
การเรียนรู้ความสัมพันธ์ที่มีความซับซ้อนมากขึ้น 
ความเข้าใจเกี่ยวกับนิวรอนเทียม การเชื่อมต่อเป็นชั้น และกระบวนการเรียนรู้ของโครงข่ายประสาท
เทียมในบทนี้ จะเป็นพื้นฐานสำหรับการศึกษาปัญญาประดิษฐ์ยุคใหม่ในบทถัดไป โดยเฉพาะการประยุกต์ใช้
โครงข่ายประสาทเทียมกับข้อมูลภาพในรูปแบบของ Convolutional Neural Network และแนวคิดของ

8.1 แนวคิดพื้นฐานของโครงข่ายประสาทเทียม 
แนวคิดของโครงข่ายประสาทเทียมได้รับแรงบันดาลใจจากระบบประสาทของสิ่งมีชีวิต โดยเฉพาะ
แนวคิดที่ว่าเซลล์ประสาทจำนวนมากสามารถรับ ส่ง และประมวลผลข้อมูลร่วมกัน เซลล์ประสาทแต่ละเซลล์
ไม่ได้ทำหน้าที่แก้ปัญหาที่ซับซ้อนเพียงลำพัง แต่การเชื่อมต่อและการทำงานร่วมกันของเซลล์ ประสาทจำนวน
มากทำให้เกิดความสามารถในการประมวลผลข้อมูลที่ซับซ้อน 
ในระบบประสาทชีวภาพ เซลล์ประสาท หรือ  Neuron มีส่วนประกอบสำคัญ ได้แก่ เดนไดรต์ 
(Dendrite) ซึ่งทำหน้าที่รับสัญญาณจากเซลล์ประสาทอื่น ตัวเซลล์ ( Cell Body) ซึ่งทำหน้าที่ประมวลผล
สัญญาณที่ได้รับ และแอกซอน (Axon) ซึ่งทำหน้าที่ส่งสัญญาณต่อไปยังเซลล์ประสาทอื่น 
แนวคิดดังกล่าวถูกนำมาประยุกต์ใช้ในการสร้างแบบจำลองทางคอมพิวเตอร์ที่ เรียกว่า นิวรอนเทียม 
(Artificial Neuron) โดยนิวรอนเทียมจะรับข้อมูลจากอินพุตหลายตัว นำข้อมูลแต่ละตัวมาพิจารณาร่วมกับ
ค่าที่แสดงระดับความสำคัญของข้อมูล จากนั้นจึงคำนวณ และสร้างผลลัพธ์เพื่อส่งต่อไปยังนิวรอนอื่นหรือใช้
เป็นผลลัพธ์ของแบบจำลอง 
ดังแสดงในรูปที่ 1 แนวคิดของนิวรอนเทียมสามารถเปรียบเทียบกับเซลล์ประสาทชีวภาพได้ใน

8.5.2. Recurrent Neural Network 
Recurrent Neural Network หรือ RNN เป็นโครงข่ายประสาทเทียมที่ออกแบบมาเพื่อจัดการกับ  
ข้อมูลที่มีลำดับ ( Sequential Data) ซึ่งข้อมูลในแต่ละตำแหน่งอาจมีความสัมพันธ์กับข้อมูลที่อยู่ก่อนหน้า
หรือภายหลัง 
ตัวอย่างข้อมูลที่มีลำดับ ได้แก่ 
• ข้อความและประโยค  
• สัญญาณเสียง  
• ข้อมูลตามเวลา  
• ลำดับเหตุการณ์  
ตัวอย่างเช่น ในประโยคหนึ่ง ความหมายของคำอาจขึ้นอยู่กับคำที่ปรากฏก่อนหน้า การประมวลผลคำ
แต่ละคำโดยพิจารณาแยกจากกันเพียงอย่างเดียวอาจไม่สามารถสะท้อนความสัมพันธ์ของข้อมูลทั้งหมดได้ 
แนวคิดสำคัญของ RNN คือการมีการเชื่อมโยงที่ทำให้ผลจากการประมวลผลในขั้นก่อนหน้าสามารถ
นำมาใช้ร่วมกับข้อมูลในขั้นปัจจุบันได้ ดังแสดงในรูปที่ 16 
 
รูปที่ 16 แนวคิดพื้นฐานของ Recurrent Neural Network ซึ่งใช้ข้อมูลจากขั้นก่อนหน้าร่วมกับข้อมูลในขั้น
ปัจจุบันในการประมวลผลข้อมูลแบบลำดับ 
กล่าวโดยง่าย RNN สามารถมองได้ว่าเป็นโครงข่ายที่มีแนวคิดเกี่ยวกับ  สถานะ (State) ซึ่งช่วยให้
ข้อมูลบางส่วนจากการประมวลผลก่อนหน้าถูกนำมาใช้ในการประมวลผลครั้งต่อไป 
ตัวอย่างการประยุกต์ใช้ RNN ได้แก่ 
• การวิเคราะห์ข้อความ  
• การรู้จำเสียง

• การพยากรณ์ข้อมูลตามเวลา

อย่างไรก็ตาม RNN แบบพื้นฐานอาจมีข้อจำกัดในการเรียนรู้ความสัมพันธ์ของข้อมูลที่อยู่ห่างกันมาก

8.5.3. Convolutional Neural Network 
Convolutional Neural Network หรือ CNN เป็นโครงข่ายประสาทเทียมที่ได้รับการออกแบบมา
เพื่อจัดการกับข้อมูลที่มี โครงสร้างเชิงพื้นที่ (Spatial Structure) โดยเฉพาะข้อมูลประเภทภาพ 
ภาพดิจิทัลสามารถมองเป็นข้อมูลที่ประกอบด้วยค่าของพิกเซลที่เรียงตัวตามตำแหน่ง ความสัมพันธ์
ระหว่างพิกเซลที่อยู่ใกล้กันจึงมีความสำคัญ ตัวอย่างเช่น กลุ่มของพิกเซลที่อยู่ติดกันอาจแสดงถึงขอบ เส้น 
หรือส่วนหนึ่งของวัตถุ 
แทนที่จะเชื่อมต่อนิวรอนทุกหน่วยเข้ากับข้อมูลทุกตำแหน่งเหมือน Fully Connected Network 
CNN ใช้ตัวกรอง หรือ  Filter เพื่อค้นหารูปแบบเฉพาะจากข้อมูล โดย Filter จะทำงานกับข้อมูลในบริเวณ
ขนาดเล็กและเคลื่อนผ่านตำแหน่งต่าง ๆ ของข้อมูล ดังแสดงในรูปที่ 18
