ปัญญาประดิษฐ์สมัยใหม่ 
 
จากเนื้อหาในบทก่อนหน้า อธิบายถึงพื้นฐานของโครงข่ายประสาทเทียม ( Neural Network) ตั้งแต่
แนวคิดของเซลล์ประสาทเทียม การกำหนดน้ำหนัก ( Weight) และไบแอส ( Bias) การใช้ฟังก์ชันกระตุ้น 
(Activation Function) ไปจนถึงการทำงานของโครงข่ายหลายชั้น ( Multi-Layer Neural Network) ความรู้
เหล่านี้เป็นพื้นฐานสำคัญของการพัฒนาปัญญาประดิษฐ์สมัยใหม่ โดยเฉพาะในกลุ่มเทคนิคที่เรียกว่า การ
เรียนรู้เชิงลึก (Deep Learning) 
เมื่อรูปแบบของข้อมูลมีความซับซ้อนมากขึ้น การใช้โครงข่ายแบบเชื่อมต่อเต็มรูปแบบ ( Fully 
Connected Network) เพียงอย่างเดียวอาจไม่เหมาะสมกับข้อมูลทุกประเภท ตัวอย่างเช่น ข้อมูลภาพมี
ความสัมพันธ์เชิงตำแหน่งระหว่างจุดภาพ ข้อมูลภาษาเกี่ยวข้องกับลำดับและความสัมพันธ์ของคำ และข้อมูล
ในรูปแบบอื่นอาจมีลักษณะเฉพาะที่แตกต่างกัน ดังนั้นจึงมีการพัฒนาโครงสร้างของ Neural Network ให้
เหมาะสมกับลักษณะของข้อมูลและงานที่ต้องการแก้ปัญหา 
ในบทนี้จะเริ่มต้นจากโครงข่ายประสาทเทียมแบบคอนโวลูชัน ( Convolutional Neural Network: 
CNN) ซึ่งเป็นตัวอย่างสำคัญของการออกแบบ Neural Network สำหรับข้อมูลภาพ จากนั้นจะศึกษาภาพรวม
ของ ปัญญาประดิษฐ์เชิงสร้างสรรค์  ซึ่งเป็นแนวทางของปัญญาประดิษฐ์ที่ไม่ได้มีหน้าที่เพียงวิเคราะห์ จำแนก 
หรือทำนายข้อมูลเท่านั้น แต่ยังสามารถเรียนรู้รูปแบบจากข้อมูลและนำไปสู่การสร้างเนื้อหาใหม่ได้ 
9.1 แนวคิดพื้นฐานของโครงข่ายประสาทเทียมแบบคอนโวลูชัน  
โครงข่ายประสาทเทียมแบบคอนโวลูชัน (Convolutional Neural Network: CNN) เป็นรูปแบบหนึ่ง
ของ Neural Network ที่ได้รับการออกแบบให้เหมาะสมกับข้อมูลที่มีโครงสร้างเชิงพื้นที่ ( Spatial Structure) 
โดยเฉพาะข้อมูลภาพ เช่น ภาพถ่าย ภาพจากกล้องวงจรปิด ภาพเอกซเรย์ หรือภาพจากกล้องในระบบ
อุตสาหกรรม 
จากบทที่ 8 โครงข่ายประสาทเทียม แบบทั่วไปสามารถประกอบด้วยชั้นข้อมูลนำเข้า ( Input Layer) 
ชั้นซ่อน (Hidden Layer) และชั้นผลลัพธ์ ( Output Layer) โดยในโครงข่ายแบบเชื่อมต่อเต็มรูปแบบ แต่ละ
หน่วยประมวลผลในชั้นหนึ่งสามารถเชื่อมต่อกับหน่วยประมวลผลจำนวนมากในชั้นถัดไป รูปแบบดังกล่าว
เหมาะสำหรับข้อมูลที่สามารถแสดงเป็นชุดของตัวแปรได้ เช่น 
• อายุ รายได้ และจำนวนปีการทำงาน  
• คะแนนสอบในแต่ละรายวิชา  
• ข้อมูลจากเซนเซอร์  
• คุณลักษณะที่ผ่านการเตรียมข้อมูลมาแล้ว

ตัวเลขที่แยกออกจากกัน แต่ค่าของแต่ละจุดภาพหรือพิกเซล ( Pixel) มีความสัมพันธ์กับตำแหน่งของพิกเซล
รอบข้าง ตัวอย่างเช่น หากต้องการตรวจสอบว่าภาพมีเส้นขอบของวัตถุอยู่หรือไม่ การพิจารณาค่าของพิกเซล
เพียงจุดเดียวมักไม่เพียงพอ แต่จำเป็นต้องพิจารณาความสัมพันธ์ระหว่างพิกเซลที่อยู่ใกล้กัน 
แนวคิดนี้เป็นจุดสำคัญที่ทำให้ CNN แตกต่างจาก Fully Connected Network 
9.1.1. ความแตกต่างระหว่าง Fully Connected Network และ CNN 
สมมติว่ามีภาพขนาด 28 × 28 พิกเซล หากเป็นภาพขาวดำ ภาพหนึ่งภาพสามารถแทนด้วยค่าจำนวน 
784 ค่า หากนำข้อมูลดังกล่าวเข้าสู่ Fully Connected Network โดยตรง อาจทำการเรียงค่าพิกเซลทั้งหมด
เป็นข้อมูลหนึ่งมิติ ดังแสดงในรูปที่ 9.1 
 
รูปที่ 9.1 การแปลงข้อมูลภาพเป็นชุดข้อมูลหนึ่งมิติเพื่อนำเข้าสู่ Fully Connected Network 
เมื่อภาพถูกแปลงเป็นรายการของตัวเลข ความสัมพันธ์เชิงตำแหน่งระหว่างพิกเซลอาจไม่ถูกนำมาใช้
โดยตรง ตัวอย่างเช่น พิกเซลสองจุดที่อยู่ติดกันในภาพอาจกลายเป็นเพียงข้อมูลสองค่าที่อยู่ในรายการจำนวน
มาก CNN จึงได้รับการออกแบบให้สามารถประมวลผลข้อมูลในลักษณะที่ยังคงโครงสร้างเชิงพื้นที่ของภาพไว้

ใน Fully Connected Network การเชื่อมต่อระหว่างหน่วยประมวลผลอาจมีจำนวนมาก เนื่องจาก
ข้อมูลจากหน่วยจำนวนมากในชั้นก่อนหน้าสามารถเชื่อมต่อไปยังหน่วยในชั้นถัดไปได้ ส่งผลให้จำนวน Weight 
เพิ่มขึ้นอย่างรวดเร็วเมื่อขนาดของข้อมูลภาพมีขนาดใหญ่ 
ในทางตรงกันข้าม CNN ใช้แนวคิดของการตรวจสอบข้อมูลเฉพาะบริเวณ ( Local Region) แทนที่จะ
เชื่อมต่อกับข้อมูลภาพทั้งหมดในครั้งเดียว โดยใช้ตัวตรวจจับรูปแบบขนาดเล็กที่เรียกว่า ตัวกรอง ( Filter) หรือ
เคอร์เนล (Kernel) เลื่อนผ่านตำแหน่งต่าง ๆ ของภาพ เพื่อค้นหารูปแบบที่สนใจ 
ตัวอย่างเช่น Filter หนึ่งตัวอาจเรียนรู้ที่จะตอบสนองต่อรูปแบบของ 
• เส้นแนวนอน  
• เส้นแนวตั้ง  
• เส้นทแยงมุม  
• ขอบของวัตถุ  
• ลวดลายหรือพื้นผิวบางประเภท  
ในระหว่างการเรียนรู้ ค่า Weight ภายใน Filter จะถูกปรับจากข้อมูลตัวอย่าง คล้ายกับแนวคิดการ
เรียนรู้ของ Neural Network ที่ศึกษาในบทก่อนหน้า ความแตกต่างคือ CNN จัดโครงสร้างการเชื่อมต่อและ
การใช้ Weight ให้เหมาะกับข้อมูลที่มีลักษณะเชิงพื้นที่ 
9.1.2. โครงสร้างเชิงพื้นที่ของข้อมูลภาพ 
ภาพดิจิทัลสามารถมองเป็นข้อมูลที่จัดเรียงตามตำแหน่ง ในภาพขาวดำ ค่าของแต่ละ Pixel อาจแสดง
ระดับความสว่าง ส่วนภาพสีมักประกอบด้วยหลายช่องสี เช่น แดง เขียว และน้ำเงิน 
สิ่งสำคัญคือ ตำแหน่งของ Pixel มีความหมายต่อการตีความภาพ หากมีการสลับตำแหน่งของ Pixel 
อย่างไม่เป็นระบบ แม้ว่าค่าตัวเลขทั้งหมดจะยังคงมีอยู่ครบ แต่ภาพที่ได้อาจไม่สามารถสื่อความหมายเดิมได้ 
ตัวอย่างเช่น ภาพตัวเลขเขียนด้วยมือมีโครงสร้างของเส้นและรูปทรงที่เกิดจาก Pixel ซึ่งอยู่ติดกัน การ
จดจำตัวเลขจึงไม่ได้พิจารณาเพียงว่าภาพมี Pixel สีเข้มจำนวนเท่าใด แต่ยังพิจารณาว่า Pixel เหล่านั้นจัดเรียง

9.1.3. แนวคิดของ Filter หรือ Kernel 
องค์ประกอบสำคัญของ CNN คือ Filter หรือ Kernel ซึ่งสามารถมองได้ว่าเป็นชุดของ Weight ขนาด
เล็กที่ใช้ตรวจสอบรูปแบบภายในบริเวณหนึ่งของภาพ 
ตัวอย่างเช่น สมมติว่า Filter มีขนาด 3 × 3 ซึ่งหมายความว่าในแต่ละครั้ง Filter จะพิจารณาข้อมูล

f(x) = max(0, x) (2) 
จากสมการที่ 2 หากค่า x มีค่ามากกว่า 0 ผลลัพธ์จะเท่ากับ x แต่หาก x มีค่าน้อยกว่า 0 ผลลัพธ์จะ
เป็น 0 ตัวอย่างเช่น 
ถ้า x = 5 จะได้ f(5) = 5 
ถ้า x = -3 จะได้ f(-3) = 0 
แนวคิดของ ReLU ถูกนำมาใช้กับผลลัพธ์จาก Convolution Layer เพื่อช่วยให้โครงข่ายสามารถ

ดังนี้

9.2.7. Fully Connected Layer 
หลังจากข้อมูลภาพผ่านกระบวนการ Convolution และ Pooling หลายขั้นตอน CNN จะได้ข้อมูล

แนวคิดของ Fully Connected Layer เหมือนกับ Neural Network ที่ศึกษาในบทที่ 8 กล่าวคือ

ความแตกต่างคือ ข้อมูลที่เข้าสู่ Fully Connected Layer ใน CNN ไม่ใช่ค่าของ Pixel ดิบจากภาพ

เป็นต้น Convolution Layer อาจช่วยค้นหารูปแบบต่าง ๆ ของภาพ เช่น ขอบ รูปร่าง หรือพื้นผิว จากนั้น
ข้อมูลคุณลักษณะที่ผ่านกระบวนการต่าง ๆ จะถูกส่งไปยัง Fully Connected Layer เพื่อรวมข้อมูลและใช้ใน
การตัดสินใจว่าภาพดังกล่าวควรอยู่ในกลุ่มใด ดังนั้น ในระดับแนวคิด สามารถมองได้ว่า  
- Convolution และ Pooling ทำหน้าที่หลักในการสกัดคุณลักษณะ  
- Fully Connected Layer ทำหน้าที่หลักในการนำคุณลักษณะมาใช้ประกอบการตัดสินใจ 
อย่างไรก็ตาม CNN สมัยใหม่บางรูปแบบอาจออกแบบส่วนของโครงข่ายแตกต่างจากตัวอย่างพื้นฐาน
นี้ ดังนั้น Fully Connected Layer จึงควรเข้าใจว่าเป็นองค์ประกอบหนึ่งของโครงสร้าง CNN แบบพื้นฐาน 
ไม่ใช่ส่วนที่จำเป็นต้องปรากฏใน CNN ทุกสถาปัตยกรรม

9.4.1. CNN กับงาน Computer Vision 
การมองเห็นของคอมพิวเตอร์ ( Computer Vision) เป็นสาขาหนึ่งของปัญญาประดิษฐ์ที่เกี่ยวข้องกับ
การทำให้คอมพิวเตอร์สามารถวิเคราะห์และตีความข้อมูลจากภาพหรือวิดีโอ 
สำหรับมนุษย์ การมองภาพและระบุวัตถุเป็นกระบวนการที่เกิดขึ้นได้อย่างรวดเร็ว ตัวอย่างเช่น มนุษย์
สามารถมองภาพและบอกได้ว่าภาพนั้นเป็นรถยนต์ สัตว์ หรือบุคคล อย่างไรก็ตาม สำหรับคอมพิวเตอร์ ภาพ
เป็นเพียงข้อมูลที่ประกอบด้วยค่าของ Pixel จำนวนมาก 
CNN ช่วยให้ระบบสามารถเรียนรู้ความสัมพันธ์และรูปแบบจากข้อมูลภาพ โดยผ่านกระบวนการ 
Feature Extraction ที่ได้ศึกษาในหัวข้อ 9.3 ทำให้ข้อมูลภาพสามารถถูกนำไปใช้กับงานต่าง ๆ ได้ 
ตัวอย่างของงาน Computer Vision ที่สามารถประยุกต์ใช้ CNN ได้แก่ 
• การจำแนกภาพ (Image Classification) 
• การตรวจจับวัตถุ (Object Detection) 
• การรู้จำหรือวิเคราะห์ใบหน้า (Face Recognition and Face Analysis) 
• การวิเคราะห์ภาพทางการแพทย์ (Medical Image Analysis) 
• การตรวจสอบคุณภาพในภาคอุตสาหกรรม (Quality Inspection)

การตรวจจับวัตถุ ( Object Detection) เป็นงานที่มีความซับซ้อนมากกว่าการจำแนกภาพ เนื่องจาก

9.4.5. การวิเคราะห์ภาพทางการแพทย์ 
ข้อมูลภาพมีบทบาทสำคัญในงานด้านการแพทย์ เช่น 
• ภาพเอกซเรย์ 
• ภาพเอกซเรย์คอมพิวเตอร์ 
• ภาพจากการตรวจด้วยคลื่นแม่เหล็กไฟฟ้า 
• ภาพจากกล้องจุลทรรศน์ 
• ภาพถ่ายทางการแพทย์ 
CNN สามารถนำมาใช้เพื่อเรียนรู้รูปแบบจากภาพเหล่านี้ และช่วยค้นหาลักษณะที่อาจเกี่ยวข้องกับ

ตัวอย่างเช่น ระบบอาจถูกพัฒนาเพื่อช่วย 
• จำแนกภาพที่มีลักษณะแตกต่างจากปกติ 
• ค้นหาบริเวณที่ควรได้รับการตรวจสอบเพิ่มเติม 
• สนับสนุนการวิเคราะห์ข้อมูลภาพจำนวนมาก 
การประยุกต์ใช้ AI ในลักษณะนี้ควรมองว่าเป็นเครื่องมือสำหรับช่วยสนับสนุนผู้เชี่ยวชาญในการ
วิเคราะห์ข้อมูล ไม่ควรนำผลลัพธ์จากระบบไปใช้เป็นข้อสรุปโดยไม่ผ่านการตรวจสอบจากผู้มีความรู้และ

ปัจจุบัน AI สามารถเรียนรู้รูปแบบจากข้อมูลจำนวนมากและนำความรู้ที่เรียนรู้มาใช้ในการสร้างข้อมูลหรือ
เนื้อหาใหม่ได้ แนวคิดดังกล่าวเป็นพื้นฐานสำคัญของ  ปัญญาประดิษฐ์เชิง สร้างสรรค์ (Generative Artificial 
Intelligence: Generative AI) 
ปัญญาประดิษฐ์เชิงสร้างสรรค์  เป็นแนวทางของปัญญาประดิษฐ์ที่มุ่งเน้นความสามารถในการสร้าง
ข้อมูลหรือเนื้อหาใหม่ โดยอาศัยแบบจำลองที่เรียนรู้รูปแบบ ความสัมพันธ์ และลักษณะต่าง ๆ จากข้อมูลที่ใช้
ในการฝึก 
ข้อมูลหรือเนื้อหาที่ ปัญญาประดิษฐ์เชิงสร้างสรรค์  สามารถสร้างได้มีหลายรูปแบบ เช่น  ข้อความ 
(Text) ภาพ (Image) เสียง (Audio) วิดีโอ (Video) โปรแกรมหรือโค้ด (Code) เป็นต้น ตัวอย่างเช่น ระบบ AI 
ที่ใช้สำหรับการจำแนกภาพอาจได้รับภาพหนึ่งภาพเป็นข้อมูลนำเข้า แล้วตอบว่าภาพนั้นเป็นภาพของวัตถุ

จากรูปที่ 9.11 AI สำหรับการวิเคราะห์หรือจำแนกข้อมูลอาจตอบคำถาม เช่น

“เขียนบทความเกี่ยวกับ Neural Network”

9.5.1. การเรียนรู้รูปแบบเพื่อสร้างข้อมูลใหม่ 
แม้ ปัญญาประดิษฐ์เชิงสร้างสรรค์  จะสามารถสร้างผลลัพธ์ได้หลากหลายรูปแบบ แต่แนวคิดพื้นฐาน
สามารถอธิบายได้ว่า แบบจำลองจะเรียนรู้รูปแบบ ( Pattern) และความสัมพันธ์ ( Relationship) จากข้อมูล
ตัวอย่างจำนวนมาก แล้วนำสิ่งที่เรียนรู้มาใช้ในการสร้างข้อมูลใหม่ 
แนวคิดดังกล่าวสามารถแสดงได้ดังนี้ 
ข้อมูลตัวอย่าง → เรียนรู้รูปแบบและความสัมพันธ์ → Generative Model → สร้างข้อมูลใหม่ 
แบบจำลองที่ใช้เรียนรู้และสร้างข้อมูลใหม่เรียกว่า แบบจำลองเชิงกำเนิด (Generative Model) 
ปัญญาประดิษฐ์เชิงสร้างสรรค์  และ Generative Model จึงมีความสัมพันธ์กัน โดยสามารถอธิบาย
อย่างง่ายได้ว่า ปัญญาประดิษฐ์เชิงสร้างสรรค์ เป็นแนวคิดหรือกลุ่มของระบบ AI ที่มีความสามารถในการสร้าง
เนื้อหาใหม่ ส่วน Generative Model คือแบบจำลองที่ใช้เป็นกลไกสำคัญในการทำให้ระบบสามารถเรียนรู้
รูปแบบและสร้างผลลัพธ์ได้ 
ตัวอย่างเช่น หากแบบจำลองเรียนรู้จากข้อมูลข้อความจำนวนมาก แบบจำลองจะเรียนรู้ลักษณะต่าง 
ๆ ของภาษา เช่น คำที่มักปรากฏร่วมกัน ลำดับของคำ โครงสร้างของประโยค ความสัมพันธ์ระหว่างข้อความ  
 ความหมายที่เปลี่ยนแปลงตามบริบท เป็นต้น เมื่อได้รับข้อความหรือคำสั่งใหม่ แบบจำลองสามารถนำรูปแบบ
ที่เรียนรู้มาใช้ในการสร้างข้อความที่มีความต่อเนื่องและสอดคล้องกับบริบท 
ในทำนองเดียวกัน หากแบบจำลองเรียนรู้จากข้อมูลภาพจำนวนมาก ก็สามารถเรียนรู้ลักษณะ เช่น  
รูปร่าง สี พื้นผิว ตำแหน่งขององค์ประกอบ  ความสัมพันธ์ระหว่างวัตถุ  จากนั้นสามารถนำรูปแบบเหล่านี้มาใช้
ในการสร้างภาพใหม่ 
จากรูปที่ 9.12 สิ่งสำคัญคือแบบจำลองไม่ได้ถูกออกแบบมาเพื่อจดจำข้อมูลตัวอย่างทีละรายการแล้ว
เลือกข้อมูลเดิมออกมาโดยตรง แต่พยายามเรียนรู้รูปแบบและโครงสร้างที่ปรากฏอยู่ในข้อมูล 
อย่างไรก็ตาม ระดับความสามารถของแบบจำลองขึ้นอยู่กับหลายปัจจัย เช่น 
• ปริมาณและคุณภาพของข้อมูล 
• ลักษณะของแบบจำลอง 
• กระบวนการฝึก 
• ขนาดและความซับซ้อนของแบบจำลอง 
• วิธีการกำหนดข้อมูลนำเข้าและเงื่อนไขในการสร้างผลลัพธ์ 
ดังนั้น แม้ ปัญญาประดิษฐ์เชิงสร้างสรรค์  จะสามารถสร้างเนื้อหาที่มีลักษณะใหม่ได้ แต่คุณภาพและ
ความเหมาะสมของผลลัพธ์ไม่ได้รับประกันว่าจะถูกต้องเสมอไป

9.5.2. ประเภทของข้อมูลที่ ปัญญาประดิษฐ์เชิงสร้างสรรค์ สามารถสร้างได้ 
ปัญญาประดิษฐ์เชิงสร้างสรรค์ สามารถประยุกต์ใช้กับข้อมูลได้หลายรูปแบบ ซึ่งเป็นเหตุผลสำคัญที่ทำ
ให้เทคโนโลยีนี้ได้รับความสนใจอย่างมาก 
• 1) การสร้างข้อความ 
การสร้างข้อความ ( Text Generation) เป็นหนึ่งในการประยุกต์ใช้ ปัญญาประดิษฐ์เชิงสร้างสรรค์  ที่
พบได้ทั่วไป ระบบสามารถสร้างเนื้อหาหลายประเภท เช่น 
• บทความ 
• รายงาน 
• คำอธิบาย 
• บทสนทนา 
• การสรุปเนื้อหา 
• เอกสารทางเทคนิค 
แบบจำลองจะใช้ข้อความหรือคำสั่งที่ได้รับเป็นส่วนหนึ่งของบริบทในการสร้างผลลัพธ์ 
ตัวอย่างเช่น ผู้ใช้อาจกำหนดคำสั่งว่า 
“อธิบายหลักการทำงานของ Neural Network สำหรับนักศึกษาระดับปริญญาตรี” 
ปัญญาประดิษฐ์เชิงสร้างสรรค์ สามารถสร้างคำอธิบายที่สอดคล้องกับหัวข้อและเงื่อนไขที่ได้รับ 
• 2) การสร้างภาพ 
การสร้างภาพ (Image Generation) เป็นการใช้แบบจำลองเพื่อสร้างภาพใหม่จากข้อมูลหรือเงื่อนไข
ที่กำหนด เช่น คำอธิบายด้วยข้อความ 
ตัวอย่างเช่น 
“สร้างภาพหุ่นยนต์กำลังทำงานในห้องปฏิบัติการ” 
แบบจำลองสามารถสร้างภาพที่มีองค์ประกอบสอดคล้องกับคำอธิบายดังกล่าว 
การสร้างภาพด้วย ปัญญาประดิษฐ์เชิงสร้างสรรค์ แตกต่างจากงาน Image Classification ที่ใช้ CNN 
ใน PART 1 โดยงาน Image Classification มีเป้าหมายเพื่อวิเคราะห์และระบุสิ่งที่ปรากฏในภาพ ส่วน 
ปัญญาประดิษฐ์เชิงสร้างสรรค์ มีเป้าหมายเพื่อสร้างภาพใหม่ตามรูปแบบหรือเงื่อนไขที่กำหนด 
ดังนั้น แม้ทั้งสองงานจะเกี่ยวข้องกับข้อมูลภาพ แต่มีวัตถุประสงค์ที่แตกต่างกัน 
• 3) การสร้างเสียง

• การแปลงข้อความเป็นเสียง

การสร้างวิดีโอ ( Video Generation) เกี่ยวข้องกับการสร้างข้อมูลภาพที่มีการเปลี่ยนแปลงตามเวลา 
ทำให้แบบจำลองต้องพิจารณาความสัมพันธ์ระหว่างภาพในแต่ละช่วงเวลา 
ตัวอย่างการประยุกต์ใช้ ได้แก่ 
• การสร้างวิดีโอจากข้อความ 
• การสร้างภาพเคลื่อนไหว 
• การสร้างสื่อประกอบการนำเสนอ 
• การสร้างเนื้อหาดิจิทัล 
• 5) การสร้างโค้ด 
การสร้างโค้ด ( Code Generation) เป็นการประยุกต์ใช้ ปัญญาประดิษฐ์เชิงสร้างสรรค์  ที่เกี่ยวข้อง
โดยตรงกับนักศึกษาวิศวกรรมคอมพิวเตอร์ 
ผู้ใช้สามารถอธิบายปัญหาหรือความต้องการด้วยภาษาธรรมชาติ จากนั้นระบบสามารถช่วยสร้างโค้ด
ที่สอดคล้องกับคำสั่ง ตัวอย่างเช่น 
“เขียนโปรแกรมภาษา Python เพื่ออ่านข้อมูลจากไฟล์และคำนวณค่าเฉลี่ย” 
ปัญญาประดิษฐ์เชิงสร้างสรรค์ สามารถสร้างโครงสร้างของโปรแกรมตามเงื่อนไขที่ได้รับ 
อย่างไรก็ตาม การสร้างโค้ดโดย ปัญญาประดิษฐ์เชิงสร้างสรรค์ ไม่ได้หมายความว่าโค้ดนั้นถูกต้องหรือ
สามารถใช้งานได้อย่างสมบูรณ์เสมอไป ผู้พัฒนายังคงจำเป็นต้องอ่าน ทำความเข้าใจ ทดสอบ และตรวจสอบ
ผลลัพธ์ที่สร้างขึ้น 
9.5.3. ตัวอย่างแนวคิดของ แบบจำลองเชิงสร้างสรรค์ 
ปัญญาประดิษฐ์เชิงสร้างสรรค์  ไม่ได้ใช้แบบจำลองเพียงประเภทเดียว นักวิจัยได้พัฒนาแนวคิดและ
สถาปัตยกรรมของ แบบจำลองเชิงสร้างสรรค์  หลายรูปแบบ โดยแต่ละแบบมีวิธีการเรียนรู้และสร้างข้อมูลที่
แตกต่างกัน 
ตัวอย่างแนวคิดที่สำคัญ ได้แก่ 
• Generative Adversarial Network 
โครงข่ายปฏิปักษ์เชิงกำเนิด ( Generative Adversarial Network: GAN) ใช้แนวคิดของแบบจำลอง
สองส่วน ได้แก่ ตัวสร้างข้อมูล (Generator) และตัวตรวจสอบข้อมูล (Discriminator)

5 
 
 
Generator มีหน้าที่สร้างข้อมูลใหม่ ส่วน Discriminator มีหน้าที่ช่วยประเมินว่าข้อมูลที่ได้รับมี
ลักษณะใกล้เคียงกับข้อมูลจริงหรือไม่ 
แนวคิดของ  GAN คือการแข่งขันระหว่างทั้งสองส่วนในระหว่างกระบวนการเรียนรู้ ซึ่งช่วยให้ 
Generator สามารถพัฒนาความสามารถในการสร้างข้อมูลที่มีลักษณะสมจริงมากขึ้น 
• Variational Autoencoder 
Variational Autoencoder (VAE) ใช้แนวคิดของการเรียนรู้การแทนข้อมูล โดยแบบจำลองพยายาม
เรียนรู้ลักษณะสำคัญและโครงสร้างของข้อมูลในรูปแบบที่สามารถนำมาใช้สร้างข้อมูลใหม่ได้ 
แนวคิดพื้นฐานสามารถมองได้ว่า  
Input Data → Encoder → Data Representation → Decoder → Generated Data 
VAE แสดงให้เห็นว่าแบบจำลองสามารถเรียนรู้โครงสร้างของข้อมูลและนำความรู้ที่ได้มาใช้ในการ
สร้างตัวอย่างใหม่ได้ 
• Transformer 
ทรานส์ฟอร์เมอร์ ( Transformer) เป็นสถาปัตยกรรมของ Neural Network ที่มีบทบาทสำคัญอย่าง
มากต่อ ปัญญาประดิษฐ์เชิงสร้างสรรค์ ในปัจจุบัน โดยเฉพาะงานที่เกี่ยวข้องกับภาษาและข้อความ 
แนวคิดสำคัญของ Transformer คือการพิจารณาความสัมพันธ์และบริบทระหว่างส่วนต่าง ๆ ของ
ข้อมูล ซึ่งช่วยให้แบบจำลองสามารถจัดการกับข้อมูลที่มีลำดับและความสัมพันธ์ซับซ้อนได้ 
Transformer เป็นสถาปัตยกรรมพื้นฐานที่สำคัญของ แบบจำลองภาษาขนาดใหญ่ ซึ่งจะกล่าวถึง
รายละเอียดในหัวข้อถัดไป 
• Diffusion Model 
แบบจำลองการแพร่ ( Diffusion Model) ใช้แนวคิดของการเรียนรู้กระบวนการสร้างข้อมูลผ่านการ
จัดการกับความสุ่มหรือสัญญาณรบกวน (Noise) 
ในระดับแนวคิด สามารถมองได้ว่าแบบจำลองเรียนรู้กระบวนการเปลี่ยนข้อมูลจากลักษณะที่มีความ
สุ่มไปสู่ข้อมูลที่มีโครงสร้างและมีความหมาย 
Random Noise → ลด Noise ทีละขั้น → Generated Data 
แนวคิดนี้ได้รับความนิยมอย่างมากในงานด้านการสร้างภาพ เนื่องจากสามารถนำมาใช้สร้างผลลัพธ์ที่
มีรายละเอียดและความซับซ้อนได้ 
การศึกษาโครงสร้างและรายละเอียดเชิงลึกของ GAN, VAE, Transformer หรือ Diffusion Model 
ต้องอาศัยความรู้ด้าน Deep Learning ในระดับสูงขึ้น สำหรับเนื้อหาในบทนี้ นักศึกษาควรเข้าใจว่า 
ปัญญาประดิษฐ์เชิงสร้างสรรค์  สามารถใช้แบบจำลองได้หลายแนวทาง และแต่ละแนวทางมีวิธีการเรียนรู้และ

9.6 แบบจำลองภาษาขนาดใหญ่และหลักการทำงาน 
แบบจำลองภาษาขนาดใหญ่ ( Large Language Model: LLM) เป็น Generative Model ประเภท
หนึ่งที่ได้รับการพัฒนาขึ้นเพื่อเรียนรู้รูปแบบของภาษาจากข้อมูลข้อความจำนวนมาก LLM สามารถนำความรู้
ที่เรียนรู้จากข้อมูลมาใช้ในการสร้างข้อความ ตอบคำถาม สรุปเนื้อหา แปลภาษา วิเคราะห์ข้อมูล และช่วย
สร้างโปรแกรมได้ 
แบบจำลองที่มีขนาดใหญ่และมีพารามิเตอร์ ( Parameter) จำนวนมาก รวมถึงผ่านการเรียนรู้จาก
ข้อมูลจำนวนมาก ทำให้แบบจำลองสามารถเรียนรู้รูปแบบและความสัมพันธ์ของภาษาได้ในระดับที่ซับซ้อน 
LLM เป็นตัวอย่างสำคัญของการนำ Neural Network และ Deep Learning มาประยุกต์ใช้กับข้อมูล

9.6.1. Context และความสัมพันธ์ของข้อความ 
ในการสนทนาหรือการอ่านข้อความ ความหมายของคำหนึ่งคำอาจขึ้นอยู่กับข้อความที่อยู่ก่อนหน้า 
ตัวอย่างเช่นคำว่า  “เขา” จะไม่สามารถทราบได้อย่างชัดเจนว่าหมายถึงบุคคลใด หากไม่มีข้อความก่อนหน้าที่
ให้ข้อมูลประกอบ  ตัวอย่างเช่น  สมชายเป็นนักศึกษาวิศวกรรมคอมพิวเตอร์ เขากำลังศึกษาเรื่อง Artificial 
Intelligence คำว่า “เขา” มีความหมายสัมพันธ์กับคำว่า “สมชาย” ที่ปรากฏก่อนหน้า 
ข้อมูลหรือข้อความที่ช่วยให้สามารถตีความความหมายได้เรียกว่า  บริบท (Context) สำหรับ LLM 
Context หมายถึงข้อมูลที่แบบจำลองสามารถนำมาพิจารณาร่วมกันในขณะที่กำลังประมวลผลและสร้าง

9.6.2. Token และการแทนข้อมูลภาษา 
คอมพิวเตอร์ไม่สามารถนำข้อความในรูปแบบภาษามนุษย์ไปใช้ในการคำนวณได้โดยตรง ดังนั้น ก่อนที่
ข้อความจะถูกนำเข้าสู่ LLM จำเป็นต้องมีการแบ่งและแปลงข้อความให้อยู่ในรูปแบบที่แบบจำลองสามารถ
ประมวลผลได้ หน่วยข้อมูลที่ใช้ในการประมวลผลเรียกว่า โทเค็น (Token) 
Token ไม่จำเป็นต้องมีขนาดเท่ากับคำหนึ่งคำเสมอไป ขึ้นอยู่กับวิธีการแบ่งข้อความของแต่ละระบบ 
Token อาจเป็น  คำหนึ่งคำ  ส่วนหนึ่งของคำ  ตัวอักษร  เครื่องหมายวรรคตอน  หรือ สัญลักษณ์พิเศษ  
ตัวอย่างเช่น ประโยค  “Artificial Intelligence is changing the world” อาจถูกแบ่งออกเป็น Token ใน
ลักษณะ  Artificial | Intelligence | is | changing | the | world | . ในบางระบบ คำที่มีความยาวหรือมี
รูปแบบเฉพาะอาจถูกแบ่งออกเป็นหลาย Token ตัวอย่างเช่น ปัญญาประดิษฐ์เชิงสร้างสรรค์  อาจถูกแบ่งเป็น
หน่วยข้อมูลมากกว่าหนึ่ง Token ตามวิธีการของ Tokenizer 
กระบวนการแบ่งข้อความเป็น Token เรียกว่า Tokenization แนวคิดพื้นฐานสามารถแสดงได้ดังนี้ 
Text → Tokenization → Token → Numerical Representation → LLM 
หลังจากข้อความถูกแบ่งเป็น Token แล้ว Token จะถูกแปลงเป็นค่าหรือตัวแทนเชิงตัวเลข เพื่อให้
สามารถนำเข้าสู่ Neural Network ได้ สำหรับผู้ใช้ทั่วไป ไม่จำเป็นต้องทราบรายละเอียดของการเข้ารหัส 
Token แต่การเข้าใจแนวคิดนี้มีความสำคัญ เนื่องจาก LLM ไม่ได้ประมวลผลข้อความทั้งหมดในลักษณะของ
ประโยคที่สมบูรณ์เพียงหน่วยเดียว แต่ประมวลผลข้อมูลในรูปแบบของ Token

• 9.7.1 Hallucination และความถูกต้องของผลลัพธ์ 
ข้อจำกัดสำคัญประการหนึ่งของ ปัญญาประดิษฐ์เชิงสร้างสรรค์  คือการสร้างข้อมูลที่ดูสมเหตุสมผล
หรือมีลักษณะน่าเชื่อถือ แต่มีเนื้อหาที่ไม่ถูกต้อง ปรากฏการณ์นี้มักเรียกว่า  การสร้างข้อมูลคลาดเคลื่อน 
(Hallucination) ตัวอย่างเช่น ผู้ใช้อาจถามระบบเกี่ยวกับหนังสือ งานวิจัย บุคคล หรือเหตุการณ์บางอย่าง 
ระบบอาจสร้างคำตอบที่มีรายละเอียดครบถ้วน เช่น 
• ชื่อหนังสือ 
• ชื่อผู้เขียน 
• ชื่อวารสาร 
• ปีที่ตีพิมพ์ 
• รายละเอียดของงานวิจัย

• 9.7.2 Bias และผลกระทบจากข้อมูลที่ใช้ในการเรียนรู้ 
แบบจำลอง AI เรียนรู้จากข้อมูล ดังนั้น ลักษณะของข้อมูลที่ใช้ในการฝึกย่อมส่งผลต่อพฤติกรรมและ
ผลลัพธ์ของแบบจำลอง หากข้อมูลมีความเอนเอียง (Bias) หรือมีการนำเสนอมุมมองของบางกลุ่มมากกว่ากลุ่ม
อื่น ผลลัพธ์ที่สร้างโดย AI ก็อาจสะท้อนความเอนเอียงดังกล่าว  ตัวอย่างเช่น หากข้อมูลที่ใช้ในการเรียนรู้มี
ตัวอย่างเกี่ยวกับอาชีพบางประเภทที่เชื่อมโยงกับกลุ่มบุคคลในลักษณะเดิมซ้ำ ๆ แบบจำลองอาจสร้างเนื้อหาที่
สะท้อนรูปแบบดังกล่าว  
Bias อาจส่งผลต่อหลายด้าน เช่น 
• การนำเสนอข้อมูล 
• การใช้ภาษา 
• การให้คำแนะนำ 
• การสร้างภาพ 
• การจัดลำดับหรือเลือกข้อมูล

• 9.7.3 Privacy และข้อมูลส่วนบุคคล

• ข้อมูลทางการเงิน 
• ข้อมูลภายในองค์กร

หรือข้อมูลที่ป้อนเข้าสู่ระบบอาจส่งผลกระทบต่อบุคคลหรือองค์กรอื่นหรือไม่

• 9.7.5 Security และการใช้ ปัญญาประดิษฐ์เชิงสร้างสรรค์ ในงานวิศวกรรมคอมพิวเตอร์

• อธิบายโค้ด 
• ช่วยสร้างตัวอย่างโปรแกรม 
• วิเคราะห์ข้อผิดพลาด 
• ช่วยออกแบบขั้นตอนวิธี 
• สรุปเอกสารทางเทคนิค 
อย่างไรก็ตาม การใช้ ปัญญาประดิษฐ์เชิงสร้างสรรค์  ในงานพัฒนาซอฟต์แวร์ยังมีประเด็นด้านความ
ปลอดภัย (Security) ที่ควรพิจารณา ตัวอย่างเช่น โค้ดที่สร้างโดย AI อาจ 
• มีช่องโหว่ด้านความปลอดภัย 
• ไม่มีการตรวจสอบข้อมูลนำเข้าอย่างเหมาะสม 
• เปิดเผยข้อมูลสำคัญผ่านการจัดการข้อผิดพลาด 
• ใช้วิธีการหรือ Library ที่ไม่เหมาะสม 
• ไม่สอดคล้องกับมาตรฐานของระบบ 
ดังนั้น แม้ ปัญญาประดิษฐ์เชิงสร้างสรรค์  จะสามารถช่วยลดเวลาในการเขียนโค้ด แต่ผู้พัฒนายังคง

สามารถนำไปใช้งานทันที แต่ควรเป็น

งาน

ผู้ใช้ควรพิจารณาข้อมูลก่อนนำเข้าสู่ระบบ AI และปฏิบัติตามนโยบายด้านความเป็นส่วนตัวของระบบ
ที่ใช้งาน 
3) เข้าใจและตรวจสอบสิ่งที่ AI สร้างขึ้น 
โดยเฉพาะในงานด้านวิศวกรรมคอมพิวเตอร์ ผู้ใช้ควรสามารถอธิบายหลักการทำงานของโค้ดที่
นำไปใช้งานได้ 
4) ใช้ AI เป็นเครื่องมือสนับสนุนการเรียนรู้ 
สำหรับนักศึกษา ปัญญาประดิษฐ์เชิงสร้างสรรค์ สามารถช่วยอธิบายแนวคิด ยกตัวอย่าง เปรียบเทียบ
วิธีการ และช่วยตรวจสอบความเข้าใจได้ แต่ไม่ควรใช้เพียงเพื่อสร้างคำตอบแล้วนำส่งโดยไม่มีการเรียนรู้หรือ
ทำความเข้าใจเนื้อหา 
5) พิจารณาผลกระทบจากการใช้งาน 
ก่อนนำผลลัพธ์ไปใช้ ควรพิจารณาว่าผลลัพธ์อาจส่งผลกระทบต่อบุคคลอื่น ความเป็นธรรม ความเป็น
ส่วนตัว หรือความปลอดภัยหรือไม่ 
 
รูปที่ 9.17 ปัญญาประดิษฐ์เชิงสร้างสรรค์ สามารถสนับสนุนการทำงานได้ แต่ผู้ใช้ยังคงมีบทบาทสำคัญในการ
ตรวจสอบและตัดสินใจ 
จากรูปที่ 9.17 แนวคิดสำคัญของการใช้ ปัญญาประดิษฐ์เชิงสร้างสรรค์  คือ การมีมนุษย์ทำหน้าที่
กำกับ  (Human Oversight) ตรวจสอบ และตัดสินใจเกี่ยวกับผลลัพธ์ที่ AI สร้างขึ้น  ปัญญาประดิษฐ์เชิง

แบบฝึกหัดท้ายบทที่ 9  
 
1. จงอธิบายความหมายของปัญญาประดิษฐ์สมัยใหม่ (Modern AI) และยกตัวอย่างการประยุกต์ใช้งานใน
ชีวิตประจำวันอย่างน้อย 3 ตัวอย่าง 
2. จงอธิบายความแตกต่างระหว่างปัญญาประดิษฐ์แบบดั้งเดิม (Traditional AI) และปัญญาประดิษฐ์สมัยใหม่ 
(Modern AI) 
3. เพราะเหตุใดปัญญาประดิษฐ์สมัยใหม่จึงสามารถแก้ปัญหาที่ซับซ้อนได้ดีกว่าปัญญาประดิษฐ์แบบดั้งเดิม 
4. Deep Learning คืออะไร และมีความสัมพันธ์กับ Artificial Intelligence และ Machine Learning 
อย่างไร 
5. จงอธิบายหลักการเรียนรู้คุณลักษณะโดยอัตโนมัติ (Automatic Feature Learning) ของ Deep Learning 
พร้อมยกตัวอย่างประกอบ 
6. จงยกตัวอย่างสถาปัตยกรรมของ Deep Learning ที่สำคัญอย่างน้อย 3 ชนิด และอธิบายลักษณะการใช้
งานของแต่ละชนิดโดยสังเขป 
7. Transformer คืออะไร และเหตุใดจึงมีความสำคัญต่อการพัฒนา AI ในปัจจุบัน 
8. กลไก Attention มีบทบาทสำคัญต่อ Transformer อย่างไร 
9. Large Language Model (LLM) คืออะไร และแตกต่างจากระบบค้นหาข้อมูล (Search Engine) อย่างไร 
10. จงอธิบายหลักการทำงานของแบบจำลองภาษาขนาดใหญ่ที่ใช้การทำนายคำถัดไป (Next Token 
Prediction) 
11. Prompt คืออะไร และเหตุใดการออกแบบ Prompt ที่เหมาะสมจึงมีผลต่อคุณภาพของผลลัพธ์ที่ได้จาก 
AI 
12. ปัญญาประดิษฐ์เชิงสร้างสรรค์ แตกต่างจาก AI แบบที่ใช้จำแนกข้อมูล (Discriminative AI) อย่างไร 
13. จงยกตัวอย่างประเภทของ ปัญญาประดิษฐ์เชิงสร้างสรรค์ อย่างน้อย 4 ประเภท พร้อมยกตัวอย่าง
เครื่องมือที่เกี่ยวข้อง 
14. จงอธิบายประโยชน์ของ ปัญญาประดิษฐ์เชิงสร้างสรรค์ ในด้านการศึกษา ธุรกิจ และอุตสาหกรรม
ซอฟต์แวร์ 
15. Hallucination คืออะไร และผู้ใช้งานควรปฏิบัติอย่างไรเพื่อป้องกันผลกระทบจากปัญหาดังกล่าว 
16. จงอธิบายแนวคิด Human + AI และแสดงความคิดเห็นว่าการทำงานร่วมกันระหว่างมนุษย์และ AI มีข้อดี
อย่างไร
