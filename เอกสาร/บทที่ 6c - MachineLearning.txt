การเรียนรู้ของเครื่อง 
 
การเรียนรู้ของเครื่อง ( Machine Learning: ML) เป็นสาขาหนึ่งของปัญญาประดิษฐ์ ( Artificial 
Intelligence: AI) ที่มุ่งเน้นการพัฒนาอัลกอริทึมและแบบจำลอง (Models) เพื่อให้ระบบคอมพิวเตอร์สามารถ
เรียนรู้จากข้อมูล และปรับปรุงประสิทธิภาพของตนเองได้โดยไม่จำเป็นต้องเขียนโปรแกรมกำหนดกฎทุก
ขั้นตอนอย่างชัดเจน (Explicitly Programmed) 
โมเดลที่ได้จากการเรียนรู้สามารถนำไปใช้ในการทำนาย ( Prediction) การจำแนกประเภท 
(Classification) หรือการตัดสินใจ ( Decision Making) สำหรับข้อมูลใหม่ที่ไม่เคยพบมาก่อน โดยอาศัย
รูปแบบ (Patterns) และความสัมพันธ์ที่เรียนรู้จากข้อมูลในอดีต 
ปัจจุบัน Machine Learning เป็นเทคโนโลยีสำคัญที่อยู่เบื้องหลังระบบต่าง ๆ มากมาย เช่น 
- ระบบแนะนำสินค้า (Recommendation Systems) 
- ระบบกรองอีเมลขยะ (Spam Filtering) 
- การรู้จำใบหน้า (Face Recognition) 
- การแปลภาษาอัตโนมัติ (Machine Translation) 
- รถยนต์ไร้คนขับ (Self-driving Cars) 
- ระบบวินิจฉัยโรคทางการแพทย์ (Medical Diagnosis) 
- โมเดลภาษาขนาดใหญ่ (Large Language Models: LLMs) 
การเรียนรู้ของเครื่องไม่ขึ้นอยู่กับภาษาโปรแกรมภาษาใดภาษาหนึ่ง สามารถพัฒนาได้ด้วยภาษา 
Matlab, C++, Java, R หรือ Python ซึ่งภาษา Python ได้รับความนิยมสูงเนื่องจากมีไลบรารีสำหรับ 
Machine Learning และ Deep Learning จำนวนมาก เช่น Scikit-Learn, TensorFlow และ PyTorch 
จุดมุ่งหมายสำคัญของ Machine Learning คือการสร้างโมเดลที่สามารถค้นหารูปแบบจากข้อมูล 
(Pattern Recognition) และนำความรู้ที่ได้ไปใช้พยากรณ์หรือตัดสินใจได้โดยมีการแทรกแซงจากมนุษย์ให้
น้อยที่สุด (Minimal Human Intervention)

ในทางตรงกันข้าม Machine Learning ไม่จำเป็นต้องกำหนดกฎสำหรับข้อมูลทุกกรณีโดยตรง แต่ให้

ดั้งเดิมอาจพยายามกำหนดกฎ เช่น รูปร่างของหู ขนาดของจมูก รูปร่างของใบหน้า หรือสีของขน แต่การ
กำหนดกฎให้ครอบคลุมภาพสุนัขและแมวทุกลักษณะเป็นเรื่องยาก 
Machine Learning จึงใช้ภาพตัวอย่างจำนวนมาก พร้อมข้อมูลที่เกี่ยวข้อง เพื่อให้โมเดลเรียนรู้
ลักษณะที่สามารถใช้แยกสุนัขออกจากแมวได้ 
6.1.1. การเรียนรู้ของเครื่องในมุมมองของปัญหาการหาค่าเหมาะสม 
แนวคิดของ Machine Learning สามารถเชื่อมโยงกับเนื้อหาเรื่องปัญหาการหาค่าเหมาะสม 
(Optimization Problem) ที่ได้ศึกษาในบทที่ 4 โดยในบทที่ 4 ได้กล่าวถึงการค้นหาคำตอบที่ดีที่สุดจากชุด
คำตอบที่เป็นไปได้ และการใช้ฟังก์ชันวัตถุประสงค์ (Objective Function) เพื่อประเมินคุณภาพของคำตอบ 
ใน Machine Learning ตัวแปรที่ต้องการปรับคือพารามิเตอร์ของโมเดล (Model Parameters) และ
เป้าหมายคือการค้นหาค่าพารามิเตอร์ที่ทำให้โมเดลสามารถทำนายข้อมูลได้ดี 
แนวคิดของการเรียนรู้ของเครื่องคือการทำให้ Loss Function มีค่าต่ำที่สุด 
กล่าวอีกนัยหนึ่ง การฝึกโมเดล การเรียนรู้ของเครื่อง สามารถมองได้ว่าเป็นปัญหา Optimization ที่
ต้องค้นหาค่าพารามิเตอร์ที่เหมาะสมที่สุด 
ตัวอย่างเช่น หากโมเดลมีพารามิเตอร์ θ เป้าหมายของการฝึก อาจเขียนได้เป็น 
θ* = arg minθ L(θ) 
โดยที่ 
θ หมายถึง พารามิเตอร์ของโมเดล 
L(θ) หมายถึง Loss Function ที่ใช้วัดความผิดพลาดของโมเดล 
θ* หมายถึงค่าพารามิเตอร์ที่ทำให้ Loss มีค่าต่ำที่สุด 
แนวคิดนี้มีความสัมพันธ์โดยตรงกับเนื้อหาเรื่อง Gradient และ Steepest Descent ที่ได้ศึกษาในบท
ที่ 4 ซึ่งเป็นแนวคิดพื้นฐานที่นำไปสู่การฝึกโมเดล Machine Learning และ Deep Learning ในบทต่อ ๆ ไป

6.1.2. Loss Function 
Loss Function หรือฟังก์ชันสูญเสีย เป็นฟังก์ชันที่ใช้วัดว่าผลลัพธ์ที่โมเดลทำนายแตกต่างจากผลลัพธ์
ที่ต้องการมากน้อยเพียงใด หากโมเดลทำนายได้ใกล้เคียงกับค่าจริง Loss จะมีค่าต่ำ ในทางกลับกัน หากโมเดล
ทำนายผิดมาก Loss จะมีค่าสูง ดังนั้นในกระบวนการฝึกโมเดล เป้าหมายโดยทั่วไปคือการปรับพารามิเตอร์ให้ 
Loss ลดลง สำหรับปัญหา Regression ตัวอย่าง Loss Function ที่นิยมใช้คือ Mean Squared Error (MSE) 
MSE = (1/n) Σ(yi - ŷi)² 
โดยที่ 
yi คือค่าจริง 
ŷi คือค่าที่โมเดลทำนาย 
n คือจำนวนข้อมูล 
ในปัญหา Classification อาจใช้ Cross-Entropy Loss ซึ่งจะกล่าวถึงในรายละเอียดเมื่อศึกษาการ
เรียนรู้แบบมีผู้สอน 
6.1.3. จาก Gradient Descent สู่การฝึกโมเดล 
จากบทที่ 4 ผู้เรียนได้ศึกษาการหาค่าที่เหมาะสมด้วย Gradient และ Steepest Descent โดย
หลักการสำคัญคือการเคลื่อนที่ไปในทิศทางที่ทำให้ค่าของฟังก์ชันลดลง 
แนวคิดดังกล่าวสามารถนำมาใช้ในการฝึก Machine Learning ได้ 
θnew = θold - η∇L(θ) 
โดยที่ 
θnew คือค่าพารามิเตอร์ใหม่ 
θold คือค่าพารามิเตอร์เดิม 
η คือ Learning Rate 
∇L(θ) คือ Gradient ของ Loss Function 
สมการนี้แสดงให้เห็นว่าการฝึกโมเดลไม่ได้เป็นเพียงการ "จดจำข้อมูล" แต่เป็นกระบวนการปรับ
พารามิเตอร์ของโมเดลอย่างต่อเนื่อง เพื่อให้ค่าความสูญเสียลดลง 
ดังนั้น ความรู้เรื่อง Optimization ในบทที่ 4 จึงเป็นพื้นฐานสำคัญสำหรับทำความเข้าใจ Machine

6.2.1. การเรียนรู้แบบมีผู้สอน (Supervised Learning) 
เป็นวิธีการเรียนรู้ที่ใช้ข้อมูลที่มีป้ายกำกับ ( Labeled Data) หรือมีคำตอบที่ถูกต้องกำกับไว้แล้ว โดย
โมเดลจะเรียนรู้ความสัมพันธ์ระหว่างข้อมูลอินพุต ( Input) และเอาต์พุต ( Output) เพื่อสร้างฟังก์ชันสำหรับ
ทำนายข้อมูลใหม่ 
การเรียนรู้ประเภทนี้เป็นวิธีที่ได้รับความนิยมมากที่สุด และสามารถแบ่งปัญหาออกได้เป็นสองลักษณะสำคัญ 
ได้แก่ 
• การจำแนกประเภท (Classification) 
• การถดถอย (Regression) 
ตัวอย่างการประยุกต์ใช้งาน ได้แก่ 
• การจำแนกภาพแมวและสุนัข 
• การวินิจฉัยโรค 
• การตรวจจับอีเมลขยะ 
• การพยากรณ์ราคาบ้าน 
• การคาดการณ์ยอดขายสินค้า 
6.2.2. การเรียนรู้แบบไม่มีผู้สอน (Unsupervised Learning) 
เป็นวิธีการเรียนรู้ที่ใช้ข้อมูลที่ไม่มีป้ายกำกับ (Unlabeled Data) โดยโมเดลจะพยายามค้นหารูปแบบ
หรือโครงสร้างที่ซ่อนอยู่ภายในข้อมูลด้วยตนเอง 
งานที่สำคัญของการเรียนรู้ประเภทนี้ ได้แก่ 
• การจัดกลุ่มข้อมูล (Clustering) 
• การลดมิติข้อมูล (Dimensionality Reduction) 
• การค้นหาความสัมพันธ์ระหว่างข้อมูล (Association Rule Learning) 
ตัวอย่างการประยุกต์ใช้งาน ได้แก่ 
• การแบ่งกลุ่มลูกค้า 
• ระบบแนะนำสินค้า 
• การวิเคราะห์พฤติกรรมผู้ใช้งาน 
• การตรวจจับความผิดปกติของข้อมูล

• ภาพหลายมุม 
• ภาพในสภาพแสงต่างกัน

6.4 ปัญหาที่พบในการเรียนรู้ของเครื่อง 
เป้าหมายสำคัญของการเรียนรู้ของเครื่อง คือ การสร้างโมเดลที่สามารถเรียนรู้รูปแบบหรือ
ความสัมพันธ์จากข้อมูลฝึก ( Training Dataset) และนำความรู้ที่ได้ไปใช้กับข้อมูลใหม่ที่ไม่เคยพบมาก่อนได้
อย่างถูกต้อง ความสามารถดังกล่าวเรียกว่า ความสามารถในการสรุปผลทั่วไป (Generalization) 
อย่างไรก็ตาม ในทางปฏิบัติ โมเดลที่สร้างขึ้นอาจไม่สามารถเรียนรู้ได้อย่างเหมาะสมเสมอไป โดย
ปัญหาที่พบได้บ่อยที่สุดมีอยู่สองลักษณะ คือ Underfitting และ Overfitting ซึ่งส่งผลโดยตรงต่อประสิทธิภาพ
ของโมเดลในการทำนายข้อมูลใหม่ 
6.4.1. Underfitting 
Underfitting เป็นปัญหาที่เกิดขึ้นเมื่อโมเดลไม่สามารถเรียนรู้รูปแบบของข้อมูลได้อย่างเพียงพอ หรือ
กล่าวอีกนัยหนึ่งคือ โมเดลมีความเรียบง่ายมากเกินไป ( Model Too Simple) ทำให้ไม่สามารถอธิบาย
ความสัมพันธ์ที่แท้จริงของข้อมูลได้ 
ลักษณะสำคัญของ Underfitting คือ โมเดลมีประสิทธิภาพต่ำทั้งบนข้อมูลฝึก ( Training Dataset) 
และข้อมูลทดสอบ ( Testing Dataset) กล่าวคือ แม้แต่ข้อมูลที่ใช้ในการฝึกโมเดลเอง โมเดลก็ยังไม่สามารถ
ทำนายได้อย่างถูกต้อง 
สาเหตุที่ทำให้เกิด Underfitting ได้แก่ 
• โมเดลมีความซับซ้อนน้อยเกินไป 
• จำนวนรอบการฝึกสอน (Epoch) มีน้อยเกินไป 
• ข้อมูลที่ใช้ในการฝึกมีปริมาณไม่เพียงพอ 
• การเลือกคุณลักษณะ (Feature Selection) ไม่เหมาะสม 
• มีการกำหนดข้อจำกัดของโมเดลมากเกินไป (Over-Regularization) 
ตัวอย่างเช่น การใช้สมการเชิงเส้นตรงในการประมาณความสัมพันธ์ของข้อมูลที่มีลักษณะเป็นเส้นโค้ง
ที่ซับซ้อน จะทำให้โมเดลไม่สามารถอธิบายรูปแบบของข้อมูลได้อย่างถูกต้อง 
แนวทางในการแก้ปัญหา Underfitting ได้แก่ 
• เลือกใช้โมเดลที่มีความซับซ้อนมากขึ้น 
• เพิ่มจำนวนรอบการฝึกสอน 
• เพิ่มจำนวนคุณลักษณะของข้อมูล 
• เพิ่มปริมาณข้อมูลสำหรับการฝึก 
--- Page 13 ---
15 
 
 
• ลดข้อจำกัดหรือพารามิเตอร์ที่ใช้ควบคุมโมเดล 
6.4.2. Overfitting 
Overfitting เป็นปัญหาที่เกิดขึ้นเมื่อโมเดลเรียนรู้รายละเอียดของข้อมูลฝึกมากจนเกินไป รวมถึง
เรียนรู้สัญญาณรบกวน (Noise) หรือข้อมูลที่เกิดขึ้นเฉพาะในชุดข้อมูลฝึก ส่งผลให้โมเดลสามารถทำนายข้อมูล
ฝึกได้อย่างแม่นยำมาก แต่ไม่สามารถนำความรู้ดังกล่าวไปใช้กับข้อมูลใหม่ได้อย่างมีประสิทธิภาพ 
ลักษณะสำคัญของ Overfitting คือ โมเดลมีความแม่นยำสูงบนข้อมูลฝึก แต่มีประสิทธิภาพลดลง
อย่างมากเมื่อประเมินกับข้อมูลตรวจสอบ (Validation Dataset) หรือข้อมูลทดสอบ (Testing Dataset) 
ตัวอย่างเช่น 
Training Accuracy = 99% 
Validation Accuracy = 84% 
Testing Accuracy = 82% 
กรณีนี้ควรสงสัยว่าโมเดลเกิด Overfitting 
 
สาเหตุที่ทำให้เกิด Overfitting ได้แก่ 
• โมเดลมีความซับซ้อนมากเกินไป 
• จำนวนพารามิเตอร์ของโมเดลมีมากเกินความจำเป็น 
• ฝึกโมเดลเป็นเวลานานเกินไป 
• ชุดข้อมูลมีขนาดเล็ก 
• มีสัญญาณรบกวน (Noise) ปะปนอยู่ในข้อมูล

6.5.1.2 Confusion Matrix 
Confusion Matrix เป็นตารางที่ใช้แสดงความสัมพันธ์ระหว่างค่าจริง ( Actual Class) กับค่าที่โมเดล
ทำนาย (Predicted Class) 
สำหรับ Binary Classification ประกอบด้วยผลลัพธ์ 4 ประเภท ได้แก่ 
Actual / Predicted Positive Negative 
Positive True Positive (TP) False Negative (FN) 
Negative False Positive (FP) True Negative (TN) 
• True Positive (TP) 
เป็นกรณีที่ข้อมูลเป็น Positive จริง และโมเดลทำนายว่าเป็น Positive 
ตัวอย่างเช่น ภาพเป็นภาพสุนัขจริง และโมเดลทำนายว่าเป็นสุนัข 
• True Negative (TN) 
เป็นกรณีที่ข้อมูลเป็น Negative จริง และโมเดลทำนายว่าเป็น Negative 
ตัวอย่างเช่น ภาพเป็นแมวจริง และโมเดลทำนายว่าไม่ใช่สุนัข 
• False Positive (FP) 
เป็นกรณีที่ข้อมูลเป็น Negative แต่โมเดลทำนายว่าเป็น Positive 
ตัวอย่างเช่น ภาพเป็นแมว แต่โมเดลทำนายว่าเป็นสุนัข 
• False Negative (FN) 
เป็นกรณีที่ข้อมูลเป็น Positive แต่โมเดลทำนายว่าเป็น Negative 
ตัวอย่างเช่น ภาพเป็นสุนัข แต่โมเดลทำนายว่าเป็นแมว 
สำหรับงานทางการแพทย์ FP และ FN มีความหมายที่แตกต่างกันอย่างมาก โดย FN หมายถึงผู้ป่วยที่
เป็นโรคจริงแต่โมเดลไม่สามารถตรวจพบ ซึ่งอาจมีผลกระทบสูงกว่าการแจ้งเตือนผิดว่าเป็นโรค 
Confusion Matrix จึงเป็นพื้นฐานสำคัญสำหรับการคำนวณ Accuracy, Precision, Recall และ F1-
score

ในงานทางการแพทย์ ผลลัพธ์ดังกล่าวอาจไม่เพียงพอสำหรับการนำไปใช้งานจริง เพราะโมเดลยัง
พลาดผู้ป่วยที่เป็นโรคถึง 40% ของผู้ป่วยทั้งหมดในตัวอย่างนี้ 
6.5.2. ROC Curve และ AUC 
ROC Curve (Receiver Operating Characteristic Curve) เป็นกราฟที่ใช้แสดงความสัมพันธ์
ระหว่าง True Positive Rate (TPR) และ False Positive Rate (FPR) เมื่อเปลี่ยน Threshold ที่ใช้ในการ
ตัดสินใจของโมเดล  
True Positive Rate สามารถคำนวณได้จาก 
TPR = TP / (TP + FN)

23 
 
 
ซึ่งมีค่าเท่ากับ Recall 
ส่วน False Positive Rate คำนวณได้จาก 
FPR = FP / (FP + TN) 
พื้นที่ใต้ ROC Curve เรียกว่า Area Under the Curve (AUC) 
โดยทั่วไป 
• AUC ใกล้ 1 หมายถึงโมเดลสามารถแยกคลาสได้ดี 
• AUC ใกล้ 0.5 หมายถึงความสามารถในการแยกคลาสใกล้เคียงกับการสุ่ม 
• AUC = 1 หมายถึงสามารถแยกคลาสได้สมบูรณ์ตามคะแนนที่ใช้สร้าง ROC 
ROC-AUC มีประโยชน์ในการเปรียบเทียบความสามารถของโมเดลในการแยกคลาส โดยไม่จำกัดอยู่ที่ 
Threshold เพียงค่าเดียว 
6.5.3. การวัดประสิทธิภาพสำหรับงานถดถอย (Regression) 
• ลักษณะของงาน Regression 
Regression เป็นงานที่โมเดลต้องทำนายค่าตัวเลขต่อเนื่อง ( Continuous Numerical Value) 
แตกต่างจาก Classification ซึ่งผลลัพธ์เป็นคลาสหรือหมวดหมู่ 
ตัวอย่างเช่น 
• ทำนายราคาบ้าน 
• ทำนายอุณหภูมิ 
• ทำนายยอดขาย 
• ทำนายปริมาณการใช้ไฟฟ้า 
• ทำนายอายุจากข้อมูลภาพหรือข้อมูลทางชีวภาพ 
ตัวอย่างเช่น หากต้องการทำนายราคาบ้าน ค่าจริงอาจเป็น 3,000,000 บาท แต่โมเดลทำนาย 
2,900,000 บาท เราสามารถคำนวณความคลาดเคลื่อนระหว่างค่าจริงกับค่าทำนายได้โดยตรง 
ดังนั้น การประเมิน Regression จะไม่ได้ใช้ Accuracy, Precision หรือ Recall แต่จะพิจารณาขนาด
ของความคลาดเคลื่อนแทน 
6.5.3.1 Mean Absolute Error (MAE) 
MAE เป็นค่าเฉลี่ยของค่าความคลาดเคลื่อนสัมบูรณ์ระหว่างค่าจริงและค่าที่โมเดลทำนาย 
MAE = (1/n) Σ |yi - ŷi| 
ค่า MAE ยิ่งต่ำ แสดงว่าโมเดลมีความคลาดเคลื่อนน้อย 
ข้อดีของ MAE คือสามารถตีความได้ง่าย เพราะมีหน่วยเดียวกับตัวแปรเป้าหมาย

6.5.3.2 Mean Squared Error (MSE) 
MSE เป็นค่าเฉลี่ยของกำลังสองของความคลาดเคลื่อน 
MSE = (1/n) Σ (yi - ŷi)² 
เนื่องจากมีการยกกำลังสอง ข้อผิดพลาดที่มีขนาดใหญ่มากจะมีผลต่อค่า MSE มากกว่าข้อผิดพลาด
ขนาดเล็ก 
6.5.3.3  Root Mean Squared Error (RMSE) 
RMSE คือรากที่สองของ MSE 
RMSE = √[(1/n) Σ (yi - ŷi)²] 
ข้อดีคือผลลัพธ์มีหน่วยเดียวกับค่าที่ต้องการทำนาย ทำให้ตีความได้ง่ายกว่า MSE 
6.5.3.4 Coefficient of Determination (R²) 
R² เป็นตัวชี้วัดที่ใช้แสดงว่าโมเดลสามารถอธิบายความแปรปรวนของข้อมูลได้มากน้อยเพียงใด 
R² = 1 - [Σ(yi - ŷi)² / Σ(yi - ȳ)²] 
โดยทั่วไปค่า R² ที่สูงแสดงว่าโมเดลสามารถอธิบายข้อมูลได้ดีขึ้น แต่ไม่ควรใช้ R² เพียงตัวเดียวในการ
ประเมินโมเดล 
6.5.4. การประเมินงานที่ไม่มี Ground Truth 
ในหัวข้อ 6.2 ได้กล่าวถึง Unsupervised Learning ซึ่งแตกต่างจาก Supervised Learning ตรงที่
ข้อมูลฝึกไม่มี Label หรือคำตอบที่ถูกต้องกำกับไว้ 
ตัวอย่างที่สำคัญคือ Clustering
