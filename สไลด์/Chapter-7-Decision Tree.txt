DEFINITION
• Decision Treesหรือ แผนภาพการตัดสินใจเป็นหนึ่งในอัลกอริทึม machine learning ที่นิยมใช้งาน ทั้งในงานด้าน
classification และ regression 
• Decision Tree มีลักษณะของข้อมูล (Node) ประกอบกันเป็นรูปของต้นไม้ (Tree) โดยแต่ละข้อมูล (Node) จะถูก
แบ่งแยกข้อมูลด้วยจุดตัดสินใจ (Decision Point) 
• ท าให้ เมื่อมีข้อมูล (Node) ใหม่เข้ามา Decision Tree จะสามารถพยากรณ์ว่า Node ควรอยู่ภายใต้จุดตัดสินใจใด

LIMITAION
• Overfitting: ง่ายต่อการเกิด overfitting กรณีข้อมูลมี noise เยอะ
• Instability: ไม่เสถียร การเปลี่ยนแปลงข้อมูลเพียงเล็กน้อย น าไปสู่การเปลี่ยนแปลงโครงสร้าง Decision Tree ได้
• Biased to Dominant Classes: ค่าการตัดสินใจ โอนเอียงไปยังกลุ่มข้อมูลส่วนใหญ่

• แตกต่างจากวิธีการ Classification ที่เป็นการพยากรณ์ว่าผลลัพธ์อยู่ในกลุ่มใด (จ านวนกลุ่มจะเป็นตัวเลขที่จ ากัด)

OPTIMIZATION ALGORITHM IN DECISION TREE
• ในการ Train Machine Learning ทุกประเภท จะต้องมี Optimization Function เพื่อท าให้ Model เรียนรู้ได้ดีขึ้น
• ในหัวข้อ Neural Network จะใช้ Mean Square Error หรือ Cross Entropy Loss เพื่อท าการลดค่า Error 
ระหว่าง Output จริงกับ Output ท านาย ให้มีค่าเข้าใกล้ 0
• ใน Decision Tree ก็ต้องมี  Optimization Function เหมือนกัน โดยจะเรียกว่า Criterion Function 
• Criterion Function จะเป็นฟังก์ชัน เพื่อค านวณค่า Error ระหว่าง Output จริงกับ Output ท านาย ให้มีค่าใกล้กัน
ที่สุด 
• Criterion Function ของ Decision Tree จะไม่มี Gradient Descent เพื่อช่วยการเรียนรู้ของ Model
