DEFINITION OF MACHINE LEARNING
• Machine Learning (ML) เป็นแขนงหนึ่งของ Artificial Intelligence ที่เพิ่มพลังคอมพิวเตอร์โดย
การเรียนรู้จากข้อมูล
• ML ไม่ได้ขึ้นกับภาษาเขียนโปรแกรมภาษาใดภาษาหนึ่ง สามารถพัฒนาได้ทั้ง Matlab C++ Java 
และ Python
• ML ใช้อัลกอริทึมเรียนรู้จากรูปแบบ (Pattern) และ ข้อมูลพิเศษ (Insight) จากข้อมูลที่ใช้สอน 
(Training Dataset)

WHY MACHINE LEARNING MATTERS?
• ML พัฒนาขึ้นให้มีความสามารถเป็นไปตาม (lies in) เป้าหมายที่ผู้สร้างต้องการ เช่น
• ใช้ในการวิเคราะห์ข้อมูลจ านวนมหาศาล ซึ่งมนุษย์ไม่สามารถเรียนรู้ข้อมูลเหล่านี้ในเวลาช่วงชีวิตได้
• การจดจ ารูปแบบ (Recognize Patterns) ซึ่งมีความน่าจะเป็นหลากหลาย การหาความสัมพันธ์จากรูปแบบ
ข้อมูลที่ป้อนขึ้น นั้นมีความหลากหลายสูงมาก
• พยากรณ์ หรือตัดสินใจโดยมีมนุษย์เข้ามาช่วยเหลือน้อยที่สุด (Minimal Human Intervention) จนถึงไม่มีเลย

KEY CONCEPTS IN MACHINE LEARNING
• Fundamental concepts in machine learning
• Supervised Learning: Learning from labeled data.
• Classification: Categorizing data into predefined classes (จ าแนกข้อมูลตามจ านวนคลาสที่ก าหนด)
• Regression: Predicting numerical values (พยากรณ์ข้อมูลที่ไม่เคยเรียนรู้มาก่อน)
• Unsupervised Learning: Learning patterns from unlabeled data.
• Clustering: Grouping similar data points (แบ่งกลุ่มข้อมูลตามจ านวนคลาสที่ก าหนด)

KEY CONCEPTS IN MACHINE LEARNING

• Few-shot supervised Learning เรียนรู้จากรูป 2 – 3 รูป
• One-shot Learning เรียนรู้จากข้อมูลรูปภาพเพียงรูป (คู่) เดียว
• Zero-shot Learning คล้าย Unsupervised Learning แต่ไม่ใช่การจัดกลุ่ม เป็น Object Detection 
หรือ Object Segmentation

SUPERVISED LEARNING
Supervised Learning เป็นหนึ่งในวิธีการเรียนรู้ของ ML
Algorithm จะเรียนรู้จาก labeled dataset 
ทุก ๆ input จะมี output ที่ต้องการ (Desire output, Ground-truth, Label) 
Model ที่ถูก Train จะพยายามค านวณ หรือ พยากรณ์ (Actual, Predicted Output) ให้ผลลัพธ์ที่ได้จาก 
Model มีค่าใกล้เคียงกับ Ground-truth
เป้าหมายของการ Train Model คือ พยากรณ์ข้อมูลที่ไม่เคยเห็นมาก่อน ให้แม่นย าเหมือนข้อมูลที่ถูก Train
(~Generalization)
